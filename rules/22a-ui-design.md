# UI設計作成（日本語）

> 元Cursorルールでの適用範囲: `specs/**/ui-design.md` を編集するとき。画面毎の部品配置と画面遷移

見出しと本文は日本語で書くこと。

`specs/templates/ui-design-template.md` に従うこと。

画面が無い場合は「画面なし」と書き、画面一覧・画面詳細・画面遷移も「なし」と明記すること。ファイルは省略しない。

画面がある場合:

- **画面一覧**を書くこと（画面ID、画面名、パス、目的）。パスは `design.md` と一致させる。
- **画面毎**に、領域ごとの部品配置と、初期 / 読込中 / 空 / エラーの表示を書くこと。ヘッダ・ナビ・画面分割は `rules/15-ui-style.md` に従う。コンテンツ領域に置く部品は、その機能の要件に合わせて決めてよい。
- **画面遷移**を書くこと（操作と行き先）。
- 色・余白・部品の見た目・共通の操作ラベル・画面分割・ナビは `rules/15-ui-style.md` に従うこと。
- 他機能の `ui-design.md` やフロント実装を参照しないこと。

起動・モジュール構成は書かないこと（`design.md`）。
API のパス・要求・応答・エラーは書かないこと（`api-design.md`）。
テーブル定義と ER 図は書かないこと（`db-design.md`）。

要件に存在しない画面や部品を追加しないこと。

ユーザが `design.md` を承認するまで、このファイルを作成しないこと。
ユーザがこのファイルを承認するまで、`db-design.md` を作成しないこと。

承認欄は履歴形式とする（日時・状態・変更概要。詳細は `CLAUDE.md`）。
