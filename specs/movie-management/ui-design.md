# movie-management UI設計

> 色・余白・部品の見た目・共通の操作ラベル・画面分割・ナビは `rules/15-ui-style.md` に従う。
> 起動・モジュール構成は書かない → `design.md`
> API のパス・要求・応答・エラーは書かない → `api-design.md`
> テーブル定義と ER 図は書かない → `db-design.md`

## 画面一覧

| SCR-002 | 動画登録 | `/register` | 動画ファイルとメタ情報の登録、サムネイル指定、アップロード進捗の表示。 |

| SCR-004 | 動画編集 | `/videos/:id/edit` | 動画情報の編集、ファイルの差し替え、削除。 |
| SCR-005 | 視聴履歴 | `/history` | 視聴履歴の一覧。 |
| SCR-006 | 作品 | `/series` | 作品の一覧・検索・登録。 |

## 共通の構成

### 殻（ヘッダ / ナビ / コンテンツ）

殻は `rules/15-ui-style.md` に従う（PC は左ナビ、768px 未満は下ナビ）。`--color-primary` は Violet `#A78BFA` とする。

| 領域 | 部品 | 説明 |
|------|------|------|
| ヘッダ | 機能名 | 「動画」。システム共通アイコンを添える。 |
| ヘッダ | 戻るボタン | `back` アイコン（`aria-label`「戻る」）。システム設定のメニュー画面 URL へ進む。 |
| ナビ | 項目 | 「動画」（SCR-001）、「プレイリスト」（SCR-009）、「履歴」（SCR-005）、「作品」（SCR-006）、「ジャンル」（SCR-008）。現在地を `--color-primary` で示す。動画登録・再生・編集は下位の画面として、その入口となる項目を現在地にする（SCR-002〜004 は「動画」、SCR-007 は「作品」、SCR-010・011 は「プレイリスト」）。 |

- ナビ項目は文字ラベルとする。動画・履歴などを表す単色アイコンが `icons/` に無いため（`rules/15-ui-style.md` の「対応するアイコンが無い操作は文字ラベルのままにする」の適用）。
- 項目数は 5 で、スマートフォンの下ナビにもそのまま並べる。

### アイコンと文字ラベルのボタン

`icons/` にあるアイコンで表せる操作はアイコンのみのボタン（`aria-label` で意味を示す）とする。表せない操作は文字ラベルのボタンとする。

| 操作 | 表現 |
|------|------|
| 追加・新規（動画登録の入口、作品・プレイリストの作成） | `plus`（`aria-label`「新規」） |
| 編集 | `edit`（「編集」） |
| 削除 | `delete`（「削除」） |
| 保存・確定 | `check`（「保存」） |
| キャンセル・閉じる・入力欄のクリア | `close`（「キャンセル」「閉じる」） |
| 一覧・上位画面へ戻る | `back`（「戻る」） |
| 検索、絞り込み、再生、続きから再生、最初から再生、一時停止、10 秒戻る、10 秒進む、全画面、次の動画、前の動画、前へ・次へ（ページ）、上へ・下へ（並び替え）、ファイルを差し替え、追加（プレイリストへの動画の追加）、外す | 対応するアイコンが無いため文字ラベル |

### 共通の表示

- 動画カード: サムネイル画像（無いときは「画像なし」と表示した枠）、タイトル、作品名と話数・話タイトル（ある場合）、ジャンル、再生時間、状態（「再生可能」以外のとき「登録中」「エラー」のラベル）、前回の再生位置を表す進捗バー、視聴完了のラベル、編集ボタン。カード本体を押すと再生画面へ進む。編集ボタンだけが編集画面へ進む。
- 再生時間・再生位置は `m:ss`（1 時間以上は `h:mm:ss`）で表示する。
- ページ送り: 「前へ」「次へ」と、現在ページ／全ページ数。先頭・末尾では該当ボタンを無効にする。
- 確認ダイアログ: 背景（オーバーレイ）を押しても閉じない。閉じる操作は、ダイアログ内の「削除」など実行のボタンと、`close`（キャンセル）のボタンだけ。
- 一覧は、ヘッダ行を固定し、本体だけスクロールする。ページ全体はスクロールさせない。
- 成功時は、対象領域の先頭に成功メッセージを数秒表示する。失敗時は、対象領域の先頭にエラーメッセージ（内部理由を含まない一文）を表示する。
- 未ログイン（認証エラー）を受けたら、画面を表示せず、ログイン画面 URL へ進む。権限なしのときは、その旨を表示する。

## 画面詳細

### SCR-001: 動画一覧

**部品配置**

| 領域 | 部品 | 説明 |
|------|------|------|
| コンテンツ上部 | 続きから視聴パネル | 最後に単独で再生した動画（タイトル・再生位置／動画の長さ）と、最後に再生したプレイリスト（プレイリスト名・動画のタイトル・再生位置）を、それぞれ 1 枚のカードで示す。各カードに「続きから再生」ボタン。片方だけのときは 1 枚。どちらも無いときはパネルごと表示しない。動画は SCR-003、プレイリストは SCR-011 へ進む。スマートフォンでの表示は下記のとおり。 |
| コンテンツ上部 | キーワード検索欄・「検索」ボタン・`close`（クリア） | プレースホルダ「タイトルで検索」。動画のタイトルまたは話タイトルの部分一致。 |
| コンテンツ上部 | 絞り込み | ジャンル（すべて／各ジャンル）、作品（すべて／各作品）、状態（再生可能／登録中／エラー／すべて。既定は再生可能）の選択。 |
| コンテンツ上部 | 並び替え | 並び項目（登録日時／タイトル／最終再生日時）と方向（降順／昇順）の選択。既定は登録日時の降順。 |
| コンテンツ上部 | 新規ボタン | `plus`。SCR-002 へ進む。 |
| コンテンツ | 動画一覧 | 動画カードを並べる（PC は複数カラムのグリッド、スマートフォンは 1 カラム）。1 ページ 20 件。 |
| コンテンツ下部 | ページ送り | 共通のページ送り。 |

スマートフォンでは、検索欄を常時表示し、絞り込みと並び替えは「絞り込み」ボタンで開閉する（既定は閉じる）。続きから視聴パネルは、一覧の表示領域を確保するため、既定で非表示にする。検索欄の行の「続きから」ボタン（「絞り込み」ボタンの隣）を押すと、表示と非表示を切り替える。続きから視聴の情報が無いときは、このボタンも表示しない。開閉の状態は保存せず、画面を開くたびに非表示から始める。PC では、これまでどおりパネルを常時表示し、「続きから」ボタンは表示しない。

**状態別の表示**

| 状態 | 表示内容 |
|------|----------|
| 初期 | 動画一覧と、続きから視聴の情報の取得を開始する。 |
| 読込中 | 一覧の領域の中央に「読み込み中…」。操作は無効。 |
| 空 | 一覧に「データがありません」。条件を指定しているときは「該当するデータがありません」。新規ボタンは有効。 |
| エラー | 対象領域の先頭にエラーメッセージ。続きから視聴の取得に失敗しても、一覧は表示する（パネルだけ出さない）。 |

### SCR-002: 動画登録

**部品配置**

| 領域 | 部品 | 説明 |
|------|------|------|
| コンテンツ上部 | 見出し・`back` | 見出し「動画登録」。`back` で SCR-001 へ戻る（登録中は無効）。 |
| フォーム | 動画ファイル | ファイル選択（MP4、必須）。選択後、検出した映像コーデックを表示する。 |
| フォーム | コーデック警告 | H.265（HEVC）と判定したとき、iPhone のブラウザで再生できない旨と、H.264 への変換コマンド例を表示する。この状態では保存できない。 |
| フォーム | タイトル | 必須、500 文字以内。 |
| フォーム | 説明 | 複数行、任意。 |
| フォーム | サムネイル画像 | ファイル選択（任意）。説明文「未指定の場合、5 秒地点（5 秒未満の動画は先頭のフレーム）から自動で作ります」。 |
| フォーム | 作品 | 「なし（単発）」／既存の作品の選択。または新しい作品のタイトルの入力（入力があれば、既存の選択より優先して新規作成する）。 |
| フォーム | 話数・話タイトル・作品内順序 | 話数は 1 以上の整数、話タイトルは 500 文字以内、作品内順序は 0 以上の整数（既定 0）。すべて任意。 |
| フォーム | ジャンル | 共通ジャンルと自分の独自ジャンルを、複数選べるチップとして並べる。 |
| フォーム | 進捗 | 保存の開始後に、進捗バーと「アップロード中 n/m」を表示する。 |
| フォーム | 操作 | `check`（保存）、`close`（キャンセル。SCR-001 へ戻る）。保存の開始後は、どちらも無効にする。 |

**状態別の表示**

| 状態 | 表示内容 |
|------|----------|
| 初期 | 空のフォーム。作品とジャンルの候補の取得を開始する。 |
| 読込中 | 候補の取得中は、作品・ジャンルの位置に「読み込み中…」。保存の開始後は、フォーム全体を無効にして進捗を表示する（「準備中…」「メタデータ登録中…」「アップロード中 n/m」「サムネイル登録中…」の順）。 |
| 空 | 作品やジャンルの候補が無いときは、その位置に「データがありません」。登録は可能。 |
| エラー | フォームの先頭にエラーメッセージ。途中で失敗したときは、登録済みの分は「登録中」の動画として残り、SCR-001 で状態を「登録中」にして確認・削除できる旨を添える。 |

保存が成功したら、SCR-001 へ進む。

### SCR-003: 動画再生

**部品配置**

| 領域 | 部品 | 説明 |
|------|------|------|
| コンテンツ上部 | `back`・タイトル | `back` で SCR-001 へ戻る。タイトルと、作品名・話数・話タイトルを示す。 |
| ステージ | 動画表示 | 動画を、画面の幅に収まる大きさで表示する。再生前はサムネイル画像を表示する。 |
| ステージ | 開始ボタン | 再生前に表示する。前回の再生位置があり、視聴完了でないときは「続きから再生」（位置を添える）と「最初から再生」の 2 つ。それ以外は「再生」のみ。 |
| ステージ | 操作部（ステージに重ねる） | シークバー（現在位置／動画の長さを添える）、「再生」／「一時停止」（切替）、「10 秒戻る」、「10 秒進む」、「全画面」、「次の動画」（次の動画があるときだけ有効）。 |
| ステージ | 状態表示 | 読み込み中（バッファリング）の表示。エラー表示。 |

- 操作部は、再生中に一定時間（3 秒）操作が無いと自動で隠す。ステージの操作（移動・タップ・キー入力）で再表示する。一時停止中、および操作部を操作している間は隠さない。
- 「全画面」でステージ（動画と操作部）を全画面にする。もう一度押すと戻す。
- 再生が最後まで終わったら、次の動画があれば、その動画を先頭から再生する（ステージの表示を切り替える）。次の動画が無いときは、視聴完了として停止し、「最初から再生」を出す。
- 「次の動画」を押すと、再生中でも次の動画へ進む。

**状態別の表示**

| 状態 | 表示内容 |
|------|----------|
| 初期 | 動画の情報を取得し、サムネイルと開始ボタンを表示する。 |
| 読込中 | ステージの中央に「読み込み中…」。情報の取得中は操作を無効にする。再生中のバッファリングでは、動画の上に「読み込み中…」を重ねる。 |
| 空 | 該当なし（動画が存在しない、または他ユーザのものは、エラーとして扱う）。 |
| エラー | ステージの先頭にエラーメッセージ。再生できない状態の動画は、その理由を示す。動画が取得できない、または形式が再生できないときは、その旨を示す。H.265（HEVC）が原因と考えられるときは、その旨と H.264 への変換方法を示す。 |

### SCR-004: 動画編集

**部品配置**

| 領域 | 部品 | 説明 |
|------|------|------|
| コンテンツ上部 | 見出し・`back` | 見出し「動画編集」。`back` で SCR-001 へ戻る。動画の状態（「再生可能」以外のとき）と、動画の長さ・ファイル形式を読み取り専用で示す。 |
| フォーム | タイトル・説明 | SCR-002 と同じ入力項目。 |
| フォーム | 作品 | 「なし（単発）」／既存の作品の選択。 |
| フォーム | 話数・話タイトル・作品内順序 | SCR-002 と同じ入力項目。 |
| フォーム | ジャンル | SCR-002 と同じチップ。選択した内容で全置換する。 |
| フォーム | 操作 | `check`（保存）、`close`（キャンセル。SCR-001 へ戻る）、`delete`（削除。確認ダイアログを開く）。 |
| ファイルの差し替え | 説明文 | 「現在の動画ファイルを削除し、選んだファイルに置き換えます。再生位置もリセットされます。」 |
| ファイルの差し替え | ファイル選択・コーデック表示・警告 | SCR-002 と同じ。H.265 と判定したときは差し替えできない。 |
| ファイルの差し替え | 「ファイルを差し替え」ボタン | 確認ダイアログを開く。確認後、進捗バーと「アップロード中 n/m」を表示する。 |
| 確認ダイアログ | 削除の確認 | 動画のタイトルを示し、削除してよいか確認する。操作は「削除」、`close`（キャンセル）。 |
| 確認ダイアログ | 差し替えの確認 | 現在のファイルが削除され、再生位置がリセットされる旨を示す。操作は「ファイルを差し替え」、`close`（キャンセル）。 |

**状態別の表示**

| 状態 | 表示内容 |
|------|----------|
| 初期 | 動画・作品・ジャンルの取得を開始する。 |
| 読込中 | 領域の中央に「読み込み中…」。差し替えの実行中は、フォーム全体を無効にして進捗を表示する。 |
| 空 | 作品やジャンルの候補が無いときは、その位置に「データがありません」。 |
| エラー | フォームの先頭にエラーメッセージ（話数の重複などを含む。内部理由は出さない）。差し替えが途中で失敗したときは、動画が「登録中」のまま残る旨と、再度の差し替えまたは削除ができる旨を添える。 |

保存・削除が成功したら SCR-001 へ進む。差し替えが成功したら、成功メッセージを表示し、動画の情報を読み直す。

### SCR-008: ジャンル

**部品配置**

| 領域 | 部品 | 説明 |
|------|------|------|
| コンテンツ上部 | 見出し・説明文 | 見出し「ジャンル」。説明文「共通ジャンルに加え、独自のジャンルを追加できます。」 |
| コンテンツ上部 | 追加フォーム | ジャンル名（必須、100 文字以内）、表示順（0 以上、既定 0）、`check`（保存）。 |
| コンテンツ | ジャンル一覧 | 表示順の昇順。1 行に、名称と「共通」または「独自」のラベル。変更・削除の操作は持たない。 |

**状態別の表示**

| 状態 | 表示内容 |
|------|----------|
| 初期 | ジャンル一覧の取得を開始する。 |
| 読込中 | 一覧の領域の中央に「読み込み中…」。 |
| 空 | 一覧に「データがありません」（共通ジャンルが登録されていれば通常は出ない）。 |
| エラー | 対象領域の先頭にエラーメッセージ。同名のジャンルがあるときは、追加フォームの先頭に「同じ名前のジャンルがあります」。 |

### SCR-009: プレイリスト一覧

**部品配置**

| 領域 | 部品 | 説明 |
|------|------|------|
| コンテンツ上部 | 見出し・新規ボタン | 見出し「プレイリスト」。`plus`（新規）で作成フォームを開く。 |
| コンテンツ | プレイリスト一覧 | 1 行に、名前、説明（省略あり）、動画の件数、「再生」ボタン、`edit`（編集）。更新日時の降順。「再生」は SCR-011 へ、編集は SCR-010 へ進む。動画が 0 件のプレイリストは、「再生」を無効にする。 |
| コンテンツ下部 | ページ送り | 共通のページ送り。 |
| 作成フォーム（モーダル） | 入力項目 | 名前（必須、500 文字以内）、説明（任意）。`check`（保存）、`close`（キャンセル）。 |

**状態別の表示**

| 状態 | 表示内容 |
|------|----------|
| 初期 | 一覧の取得を開始する。 |
| 読込中 | 一覧の領域の中央に「読み込み中…」。 |
| 空 | 一覧に「データがありません」。新規ボタンは有効。 |
| エラー | 対象領域の先頭にエラーメッセージ。作成に失敗したときは、フォームを残し、フォームの先頭にエラーメッセージ。 |

作成に成功したら、その SCR-010 へ進む（動画を追加するため）。

### SCR-010: プレイリスト編集

**部品配置**

| 領域 | 部品 | 説明 |
|------|------|------|
| コンテンツ上部 | 見出し・`back` | 見出し「プレイリスト編集」。`back` で SCR-009 へ戻る。 |
| フォーム | 名前・説明 | SCR-009 の作成フォームと同じ入力項目。 |
| フォーム | 動画の並び | 含める動画を並び順に表示する。1 行に、サムネイル、タイトル、再生時間、「上へ」「下へ」（先頭では上へ、末尾では下へを無効にする）、`close`（外す）。 |
| フォーム | 動画の追加 | 「追加」の入力欄（キーワードで動画を検索し、「再生可能」の動画を選ぶ）。選んだ動画は、並びの末尾に加える。同じ動画を複数回加えてもよい。スマートフォンでは、「動画を追加」ボタンで開閉する（既定は閉じる）。 |
| フォーム | 操作 | `check`（保存。名前・説明・動画の並びをまとめて更新する）、`close`（キャンセル。SCR-009 へ戻る）、`delete`（削除。確認ダイアログを開く）。 |
| 確認ダイアログ | 削除の確認 | プレイリストの名前を示し、削除してよいか確認する。含まれる動画は削除されない旨を示す。操作は「削除」、`close`（キャンセル）。 |

**状態別の表示**

| 状態 | 表示内容 |
|------|----------|
| 初期 | プレイリストの取得を開始する。 |
| 読込中 | 領域の中央に「読み込み中…」。 |
| 空 | 動画の並びに「データがありません」。追加は可能。 |
| エラー | フォームの先頭にエラーメッセージ（内部理由は出さない）。 |

保存が成功したら、成功メッセージを表示する（画面はそのまま）。削除が成功したら SCR-009 へ進む。

### SCR-011: プレイリスト再生

**部品配置**

| 領域 | 部品 | 説明 |
|------|------|------|
| コンテンツ上部 | `back`・プレイリスト名・動画のタイトル | `back` で SCR-009 へ戻る。 |
| ステージ | 動画表示・開始ボタン・操作部・状態表示 | SCR-003 と同じ。開始ボタンは、そのプレイリストで最後に再生した動画と位置があれば「続きから再生」と「最初から再生」（先頭の動画から）、無ければ「再生」。 |
| ステージ | 操作部の追加 | 「前の動画」（前の動画があるときだけ有効）、「次の動画」（次の動画があるときだけ有効）。 |

- 再生が最後まで終わったら、次の動画があれば、その動画を先頭から再生する。次の動画が無いときは停止する。
- 「前の動画」「次の動画」で移動した動画は、先頭から再生する。
- 操作部の自動非表示・全画面は SCR-003 と同じ。

**状態別の表示**

| 状態 | 表示内容 |
|------|----------|
| 初期 | プレイリストの情報の取得を開始し、開始ボタンを表示する。 |
| 読込中 | SCR-003 と同じ。 |
| 空 | 動画を含まないプレイリストは、「このプレイリストには動画がありません」と表示し、再生の操作はできない。SCR-010 へ進むための「編集」ボタン（`edit`）を出す。 |
| エラー | SCR-003 と同じ。再生できない状態の動画に当たったときは、その理由を示し、前後の動画へは移動できる。 |

## レイアウトの違い（PC とスマートフォン）

`rules/31-web-app-responsive-layout-spec.md` に従い、業務ロジックは共通、配置だけを変える。

| 画面 | PC（768px 以上） | スマートフォン（768px 未満） |
|------|-------------------|------------------------------|
| 共通 | 左ナビ | 下ナビ（5 項目） |
| SCR-001 | 動画カードの複数カラムのグリッド。絞り込み・並び替えは常時表示。 | 1 カラム。絞り込み・並び替えは「絞り込み」ボタンで開閉。 |
| SCR-002・004 | フォームは幅を制限した 1 カラム。ジャンルのチップは折り返して並べる。 | 1 カラム。 |
| SCR-003・011 | ステージを大きく表示し、その下に情報。操作部はステージに重ねる。 | ステージを画面の幅いっぱいに表示。操作部はタップで表示・非表示を切り替える（ホバーに依存しない）。全画面は端末の全画面表示。 |
| SCR-010 | 「動画の並び」と「動画の追加」を左右に並べて同時に表示する。 | 「動画の並び」を先に表示し、「動画の追加」は「動画を追加」ボタンで開閉する。 |
| SCR-005〜009 | 一覧の行。 | 同じ行を 1 カラムで表示。 |

- ページ全体はスクロールさせない。一覧・フォーム本体・ダイアログの中身は、部品内でスクロールしてよい。
- 主なタップ領域は 44px × 44px 以上とする。
