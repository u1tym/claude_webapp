| コンテンツ上部 | 中項目選択 | 選択中の大項目に属する、未削除の中項目から選ぶ。選ぶとノウハウ一覧の対象になる。検索確定中は表示しない。 |
| コンテンツ上部 | 中項目の追加ボタン | 大項目を選んでいるときだけ有効。中項目の登録フォームを開く。 |
| コンテンツ上部 | 中項目の名称変更ボタン | 中項目を選んでいるときだけ有効。名称変更フォームを開く（既定値は選択中の中項目名）。 |
| コンテンツ上部 | 中項目の削除ボタン | 中項目を選んでいるときだけ有効。削除確認ダイアログを開く。 |
| コンテンツ | ノウハウ一覧 | 選択中の中項目に属する未削除のノウハウを表示順に一覧表示する（検索確定中は検索結果を一覧表示する）。行を選ぶと詳細表示を開く。検索結果の各行には、所属する大項目・中項目の名称（未分類なら「未分類」）を添える。 |

| 削除確認ダイアログ | 操作 | 削除・キャンセル。 |

**文言（本機能固有）**

`rules/15-ui-style.md` の共通語彙に無い、本機能固有の操作ラベル。アイコンに対応する画像が無いため、次の操作はアイコンではなく文字ラベルのボタンとする（`rules/15-ui-style.md` の「対応するアイコンが無い操作は文字ラベルのボタンのままにする」の適用）。

| 語 | 用途 |
|------|------|
| 検索 | キーワード検索欄のプレースホルダ・検索ボタン |
| 上へ / 下へ | 並び替えモードでの表示順入れ替えボタン |

並び替えモード切替ボタンは `config`（歯車）アイコンを使う（元アプリの「設定」ボタンに相当）。大項目・中項目・ノウハウの追加は `plus`、名称変更は `edit`、削除は `delete`、保存は `check`、キャンセル・戻るは `close`、詳細表示から一覧に戻るヘッダの「戻る」は `back` を使う。

**状態別の表示**

| 状態 | 表示内容 |
|------|----------|
| 初期 | 大項目一覧の取得を開始する。大項目・中項目とも未選択。 |
| 読込中 | 領域の中央に「読み込み中…」。操作は無効。 |
| 空（大項目なし） | 大項目選択の位置に「データがありません」。追加は可能。 |
| 空（中項目なし） | 中項目選択の位置に「データがありません」。大項目を選んでいれば追加は可能。 |
| 空（ノウハウなし） | 一覧に「データがありません」。中項目を選んでいれば新規登録は可能。 |
| 空（検索結果なし） | 一覧に「該当するデータがありません」。 |
| エラー | 対象領域の先頭にエラーメッセージ（内部理由は出さない）。未ログインは表示せずログイン画面へ進む。 |

登録・変更・削除・並び替えの成功時は、対象領域の先頭に成功メッセージを数秒表示する。

ページ全体はスクロールさせず、一覧本体だけスクロールする（`rules/15-ui-style.md` の前提に従う）。

## 画面遷移

単一画面のため、画面間の遷移はない。一覧表示・詳細表示の切り替えと、モーダルの開閉のみ。

| 画面 | 操作 | 結果 |
|------|------|------|
| SCR-001 | 大項目を選ぶ | その大項目の中項目選択を表示する |
| SCR-001 | 中項目を選ぶ | その中項目のノウハウ一覧を表示する |

| SCR-001（詳細表示） | 戻るボタン | 詳細表示を閉じ、一覧に戻る |
| SCR-001（詳細表示） | 並び替えモード切替ボタン（編集として） | 詳細表示を閉じ、編集フォームを開く |
| SCR-001 | 並び替えモード切替ボタン | 並び替えモードの入/切を切り替える |
| SCR-001 | 大項目・中項目・ノウハウの追加ボタン | それぞれの登録フォームを開く |
| SCR-001 | 大項目・中項目の名称変更ボタン | 選択中の名称を初期値にした名称変更フォームを開く |
| SCR-001 | 大項目・中項目・ノウハウの削除ボタン | 削除確認ダイアログを開く |

| SCR-001（削除確認） | 削除 | 成功すれば一覧を更新してダイアログを閉じる。失敗すればエラーを示す。 |
