# UI設計: room（ROOM）

> 色・余白・部品の見た目・共通の操作ラベル・画面分割・ナビは `rules/15-ui-style.md` に従う。
> 起動・モジュール構成は書かない → `design.md`
> API のパス・要求・応答・エラーは書かない → `api-design.md`
> テーブル定義と ER 図は書かない → `db-design.md`

## 概要

この機能の画面構成と、画面毎の部品配置。`requirements.md` の該当 REQ を満たすことだけを書く。

色・余白・部品の見た目、画面分割とナビは `rules/15-ui-style.md` に従う。コンテンツ領域に置く部品は、この機能の要件に合わせて決める。他機能の画面は参照しない。`--color-primary` は Violet `#A78BFA` とする。ON / OFF や施錠中 / 開錠中の区別は、色だけに頼らず、形・記号・文言を併用する（REQ-002）。独自色は置かない。画面の表示文言は日本語とする。

関連ドキュメント:

- 全体設計: `design.md`
- DB設計: `db-design.md`
- API設計: `api-design.md`

## 共通UI

ヘッダとナビの形は `rules/15-ui-style.md`。ログイン画面とメニュー画面は持たない。殻を使う。

| 部品 | 配置箇所 | 役割 |
|------|----------|------|
| 戻る | ヘッダ | テキストボタン。戻るアイコン（`icons/back.svg`）のみ。`aria-label` は「戻る」。メニュー画面 URL へ進む。 |
| 見出し | ヘッダ | 現在の画面名（「ROOM」または「定期実行」）。 |
| システムアイコン | ヘッダ | システム全体を表すアイコン。押しても遷移しない。 |

| ナビ「定期実行」 | ナビ | 定期実行画面（SCR-002）へ進む。現在地なら選択表示にする。 |

PC ではナビを左に固定し、スマートフォンでは下端に固定する（項目は 2 つ）。

未ログインで画面を開いたときは、内容を見せずログイン画面 URL へ進む。本機能が割り当てられていないときは、内容を見せず、コンテンツに「この機能は利用できません」と戻る操作だけを示す。

## 画面詳細

### SCR-001: ROOM

- パス: `/portal_room/`
- 目的: 5 機器の状態を 1 つの図で一目で確認し、そのまま切り替える。
- 対応 REQ: REQ-001〜REQ-007

**部屋の図**

部屋を上から見た 1 枚の SVG とし、5 機器をパーツとして置く。図は画面幅に合わせて拡大縮小する（縦横比は保つ）。各パーツには、機器名と現在の状態の文言を、図の中に添える。

| パーツ | 機器 | 位置の意図 | ON / 施錠中 | OFF / 開錠中 |
|--------|------|------------|-------------|--------------|
| 電灯 | 電灯 | 天井の中央 | 点灯の形（塗りつぶし＋光線）と「ON」。※未実装のため通常は現れない | 消灯の形（輪郭のみ）と「OFF」。常にこの表示。未実装であることを示す小さな「未実装」の文言を添える |
| 間接照明 | 間接照明 | 部屋の隅 | 灯りの形（塗りつぶし＋放射状の光）と「ON」 | 灯りの形（輪郭のみ）と「OFF」 |
| 屋内スピーカー | 屋内スピーカー | 居室側 | スピーカーの形（塗りつぶし＋音波の記号）と「ON」 | スピーカーの形（輪郭のみ、音波なし）と「OFF」 |
| 枕元スピーカー | 枕元スピーカー | ベッドの枕元 | 屋内スピーカーと同じ形式で「ON」 | 同じ形式で「OFF」 |
| 玄関ドア | 玄関ドア | 部屋の入口側 | 閉じた錠の記号と「施錠中」 | 開いた錠の記号と「開錠中」 |
| 電池残量 | 玄関ドアの電池 | 玄関ドアのすぐ近く | 電池の形に残量の割合を示す塗りと「NN%」を添える（表示のみ） | （同左） |

パーツの操作:

| パーツ | 操作 | 動作 |
|--------|------|------|
| 間接照明、屋内スピーカー、枕元スピーカー | クリック／タップ／キーボード（Enter・Space） | 現在が ON なら OFF に、OFF なら ON に切り替える。 |
| 玄関ドア | クリック／タップ／キーボード | 確認ダイアログを出す。確定したときだけ、施錠中なら開錠に、開錠中なら施錠に切り替える。 |
| 電灯 | クリック／タップ／キーボード | 何も起きない。 |
| 電池残量 | クリック／タップ | 何も起きない。クリックできる見た目にはしない。 |

- 操作できるパーツは、タップ領域を 44px × 44px 以上とし、フォーカスリング（`--color-primary`）を出す。ホバーは補助の見た目に限る（ホバー専用の機能は置かない）。
- 操作できるパーツの `aria-label` は、機器名、現在の状態、押したときの結果を示す（例: 「間接照明 ON。押すと OFF にします」）。
- 電灯は、操作できない部品の見た目にする（ボタンとしては見せない）。ただし、機器名と状態は読めるようにする。
- 状態を取得できなかった機器のパーツは、輪郭を破線にして薄く示し、「取得できません」と警告の記号を添える。このパーツは切り替えられない（現在の状態が分からないため）。
- 切り替え中のパーツは、「切替中…」の文言を示す。

**部品配置**

##### PC（768px 以上）

```
┌──────────────────────────────┬──────────────┐
│                              │ 取得日時     │
│                              │ [更新]       │
│        部屋の図              ├──────────────┤
│                              │ 一括切替     │
│                              │ [屋内SP選択] │
│                              │ [枕元SP選択] │
│                              │ [電灯選択]   │
│                              │ [間接照明選択]│
│                              │ [お出かけ]   │
├──────────────────────────────┴──────────────┤
│ ステータス（1 行）／機器ごとの結果           │
└─────────────────────────────────────────────┘
```

| 領域 | 部品 | 説明 |
|------|------|------|
| 左 | 部屋の図 | 上記のとおり。 |
| 右上 | 見出し／Caption | 「取得日時」と、年月日時分秒（日本標準時）。 |
| 右上 | テキストボタン | 「更新」。状態を取得し直す。取得中は無効にする。 |
| 右 | 見出し | 「一括切替」。 |
| 右 | 副ボタン（5 つ） | 「屋内スピーカー選択」「枕元スピーカー選択」「電灯選択」「間接照明選択」「お出かけ」。縦に並べる。押すとその一括切替を実行する。確認は挟まない。実行中は 5 つとも無効にする。文字ラベルを持たせる（機能の区別にアイコンが使えないため）。 |
| 下 | ステータス | 常に 1 行分の高さを確保する。成功は一文、失敗は一文（`--color-danger`）。一括切替で一部の機器が失敗したときは、成功した機器と失敗した機器の名称を示す（REQ-007）。数秒で消してよい成功を除き、失敗は次の操作まで残す。 |

##### スマートフォン（768px 未満）

```
┌─────────────────┐

├─────────────────┤
│   部屋の図      │
├─────────────────┤
│ 一括切替        │
│ [屋内SP][枕元SP]│
│ [電灯 ][間接照明]│
│ [お出かけ      ]│
├─────────────────┤
```

| 領域 | 部品 | 説明 |
|------|------|------|
| 上 | 取得日時と更新 | 取得日時を左、「更新」を右に置く。 |
| 中 | 部屋の図 | 幅いっぱいに表示する。パーツはすべて識別できる大きさを保つ（REQ-002）。 |
| 下 | 一括切替 | 副ボタンを 2 列に並べる。「お出かけ」は幅いっぱいにする。 |
| 下 | ステータス | PC と同じ。 |

ページ全体はスクロールさせない。収まらない場合は、図と一括切替の領域を、それぞれ部品内でスクロールさせてよい。

**確認ダイアログ（玄関ドア）**

| 部品 | 説明 |
|------|------|
| 文面 | 施錠するときは「玄関ドアを施錠します。よろしいですか?」、開錠するときは「玄関ドアを開錠します。よろしいですか?」。開錠のときは、「開錠すると、玄関のドアが開けられる状態になります。」の一文を添える。 |
| 主ボタン | 「確定」。押すと切り替えを実行する。 |
| 副ボタン | 「キャンセル」。押すと状態を変えずに閉じる。 |

背景を押しても閉じない（`rules/15-ui-style.md`）。

**状態別の表示**

| 状態 | 表示内容 |
|------|----------|
| 初期 | 画面を開くと同時に状態を取得する。取得が終わるまで「読込中」を示す。取得後、部屋の図、取得日時、一括切替を示す。 |
| 読込中 | 部屋の図の領域の中央に「読み込み中…」。更新、一括切替、パーツの操作は無効。更新ボタンを押した場合も同じ（直前の図は残してよい）。 |
| 空 | なし（機器は 5 つで固定のため、空の状態は無い）。 |
| エラー | 全機器の取得に失敗したときは、図の領域の先頭に「状態を取得できませんでした。」（`--color-danger`）。操作は更新だけ有効。一部の機器だけ失敗したときは、図は表示し、失敗した機器のパーツに「取得できません」を示す。切り替えの失敗は、ステータスに一文で示し、図は元の状態のままにする。 |

### SCR-002: 定期実行

- パス: `/portal_room/schedules`
- 目的: 定期実行の定義を確認し、登録・変更・削除・有効／無効の切替をする。最終実行の結果を確認する。
- 対応 REQ: REQ-008〜REQ-010

**部品配置**

##### PC（768px 以上）

```
┌─────────────────────────────────────────────┐
│ 定期実行                              [新規]│
├────┬────────┬──────┬──────────┬──────────┬──┤
│有効│実行条件│時刻  │一括切替  │最終実行  │操作│
├────┼────────┼──────┼──────────┼──────────┼──┤
│ ○  │毎日    │07:00 │…         │…         │✎ 🗑│
└────┴────────┴──────┴──────────┴──────────┴──┘
│ ステータス（1 行）                           │
```

| 領域 | 部品 | 説明 |
|------|------|------|
| 上 | 見出し | 「定期実行」。 |
| 上 | 主ボタン | 新規アイコン（`icons/new.svg`）。`aria-label` は「新規」。定期実行入力（登録）を開く。 |
| 本体 | 一覧 | ヘッダ行は固定し、本体だけスクロールする。行内の横スクロールはしない。並びは時刻の昇順、同じ時刻なら実行する一括切替の名称順。 |
| 一覧の列 | 有効 | 有効／無効の切替。押すとその場で切り替える。状態は形と文言（「有効」「無効」）でも示す。無効の行は薄く示す。 |
| 一覧の列 | 実行条件 | 「毎日」、曜日の指定は「月・水・金」のように選んだ曜日を月曜から順に、祝日の指定は「祝日」。 |
| 一覧の列 | 時刻 | `HH:MM`。 |
| 一覧の列 | 一括切替 | 実行する一括切替の名称（屋内スピーカー選択、枕元スピーカー選択、電灯選択、間接照明選択、お出かけ）。 |
| 一覧の列 | 最終実行 | 最後に実行した年月日時分と、結果（「成功」「一部失敗」「失敗」）。失敗が含まれるときは、失敗した機器の名称を併せて示す。未実行なら「未実行」。結果は色だけでなく、文言と記号でも区別する。 |
| 一覧の列 | 操作 | 編集アイコン（`icons/edit.svg`、`aria-label` は「編集」）と削除アイコン（`icons/delete.svg`、`aria-label` は「削除」）。削除は右端。 |
| 下 | ステータス | 常に 1 行分の高さを確保する。成功は一文、失敗は一文（`--color-danger`）。 |

##### スマートフォン（768px 未満）

一覧は表ではなく、1 件 1 枚のカード（単一カラム）で示す。

| 領域 | 部品 | 説明 |
|------|------|------|
| 上 | 見出しと新規 | 見出し「定期実行」と、新規アイコン。 |
| 本体 | カード | 1 行目に時刻と有効／無効の切替。2 行目に実行条件と一括切替の名称。3 行目に最終実行（日時と結果）。末尾に編集アイコンと削除アイコン。 |
| 下 | ステータス | PC と同じ。 |

**定期実行入力（モーダル）**

登録と変更で共通。新規のときは空（実行条件は未選択、有効は ON）、変更のときは現在の値を入れる。背景を押しても閉じない。

| 部品 | 説明 |
|------|------|
| 実行条件 | 3 択（毎日／曜日の指定／祝日の指定）のラジオ。 |
| 曜日 | 実行条件が「曜日の指定」のときだけ出す。月・火・水・木・金・土・日の 7 つの切替チップ。1 つ以上を選ぶ。選択は色だけでなくチェックの記号でも示す。 |
| 時刻 | 時と分（`HH:MM`）の入力。日本標準時。 |
| 一括切替 | 5 種（屋内スピーカー選択、枕元スピーカー選択、電灯選択、間接照明選択、お出かけ）から 1 つを選ぶ。玄関ドアの施錠・開錠は選択肢に含めない。 |
| 有効 | 有効／無効の切替。 |
| 主ボタン | 保存アイコン（`icons/check.svg`）。`aria-label` は「保存」。 |
| 副ボタン | 「キャンセル」。閉じるアイコン（`icons/close.svg`）。入力を破棄して閉じる。 |
| エラー | 入力が不正なとき、モーダルの先頭に一文（`--color-danger`）。保存はされない。 |

**確認ダイアログ（削除）**

「この定期実行を削除します。よろしいですか?」。「確定」と「キャンセル」。背景を押しても閉じない。

**状態別の表示**

| 状態 | 表示内容 |
|------|----------|
| 初期 | 画面を開くと同時に一覧を取得する。 |
| 読込中 | 一覧の領域の中央に「読み込み中…」。操作は無効。 |
| 空 | 一覧の本体に「データがありません」。新規は押せる。 |
| エラー | 一覧の領域の先頭に「定期実行を取得できませんでした。」（`--color-danger`）。操作は可能なら維持する。保存・削除・切替の失敗は、ステータスまたはモーダルの先頭に一文で示す。 |
