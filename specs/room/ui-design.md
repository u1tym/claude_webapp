# UI設計: room（ROOM）

> 色・余白・部品の見た目・共通の操作ラベル・画面分割・ナビは `rules/15-ui-style.md` に従う。
> 起動・モジュール構成は書かない → `design.md`
> API のパス・要求・応答・エラーは書かない → `api-design.md`
> テーブル定義と ER 図は書かない → `db-design.md`

## 概要

この機能の画面構成と、画面毎の部品配置。`requirements.md` の該当 REQ を満たすことだけを書く。

色・余白・部品の見た目、画面分割とナビは `rules/15-ui-style.md` に従う。コンテンツ領域に置く部品は、この機能の要件に合わせて決める。他機能の画面は参照しない。`--color-primary` は Violet `#A78BFA` とする。ON / OFF や施錠中 / 開錠中の区別は、色だけに頼らず、形・記号・文言を併用する（REQ-002）。独自色は置かない。画面の表示文言は日本語とする。

関連ドキュメント:

- 全体設計: `design.md`
- DB設計: `db-design.md`
- API設計: `api-design.md`

## 共通UI

ヘッダとナビの形は `rules/15-ui-style.md`。ログイン画面とメニュー画面は持たない。殻を使う。

| 部品 | 配置箇所 | 役割 |
|------|----------|------|
| 戻る | ヘッダ | テキストボタン。戻るアイコン（`icons/back.svg`）のみ。`aria-label` は「戻る」。メニュー画面 URL へ進む。 |
| 見出し | ヘッダ | 現在の画面名（「ROOM」または「定期実行」）。 |

| ナビ「定期実行」 | ナビ | 定期実行画面（SCR-002）へ進む。現在地なら選択表示にする。 |
| 確認ダイアログ | モーダル | 玄関ドアの施錠・開錠の確認、定期実行の削除の確認。「確定」と「キャンセル」。背景（オーバーレイ）を押しても閉じない。 |

PC ではナビを左に固定し、スマートフォンでは下端に固定する（項目は 2 つ）。

未ログインで画面を開いたときは、内容を見せずログイン画面 URL へ進む。本機能が割り当てられていないときは、内容を見せず、コンテンツに「この機能は利用できません」と戻る操作だけを示す。

## 画面詳細

### SCR-001: ROOM

- パス: `/portal_room/`
- 目的: 5 機器の状態を 1 つの図で一目で確認し、そのまま切り替える。
- 対応 REQ: REQ-001〜REQ-007

**部屋の図**

壁で囲んだ 1 枚の SVG とし、5 機器と電池残量を、2 列 × 3 行に並べる。並びは、左 → 右、上 → 下の順で、次のとおり（キーボードのフォーカスと、読み上げも、この順）。壁以外の飾り（ベッド、玄関の切れ目など）は描かない。

```
電灯              間接照明
屋内スピーカー    枕元スピーカー
玄関ドア          電池残量
```

図は画面幅に合わせて拡大縮小する（縦横比は保つ）。各パーツには、機器名と現在の状態の文言を、図の中に添える。

| パーツ | 機器 | 位置 | ON / 施錠中 | OFF / 開錠中 |
|--------|------|------------|-------------|--------------|
| 電灯 | 電灯 | 左の列・1 行目 | 点灯の形（塗りつぶし＋光線）と「ON」 | 消灯の形（輪郭のみ）と「OFF」 |
| 間接照明 | 間接照明 | 右の列・1 行目 | 灯りの形（塗りつぶし＋放射状の光）と「ON」 | 灯りの形（輪郭のみ）と「OFF」 |
| 屋内スピーカー | 屋内スピーカー | 左の列・2 行目 | スピーカーの形（塗りつぶし＋音波の記号）と「ON」 | スピーカーの形（輪郭のみ、音波なし）と「OFF」 |
| 枕元スピーカー | 枕元スピーカー | 右の列・2 行目 | 屋内スピーカーと同じ形式で「ON」 | 同じ形式で「OFF」 |
| 玄関ドア | 玄関ドア | 左の列・3 行目 | 閉じた錠の記号と「施錠中」 | 開いた錠の記号と「開錠中」 |
| 電池残量 | 玄関ドアの電池 | 右の列・3 行目（玄関ドアと同じ行） | 電池の形に残量の割合を示す塗りと「NN%」を添える（表示のみ） | （同左） |

パーツの操作:

| パーツ | 操作 | 動作 |
|--------|------|------|
| 間接照明、屋内スピーカー、枕元スピーカー | クリック／タップ／キーボード（Enter・Space） | 現在が ON なら OFF に、OFF なら ON に切り替える。 |
| 玄関ドア | クリック／タップ／キーボード | 確認ダイアログを出す。確定したときだけ、施錠中なら開錠に、開錠中なら施錠に切り替える。 |
| 電灯 | クリック／タップ／キーボード | 調光パターンダイアログ（後述）を出す。パターンを選ぶと、そのパターンで電灯を ON にする（ON のときは、パターンを変える）。ダイアログの「消灯」を押すと、OFF にする（ON のときだけ出す）。 |
| 電池残量 | クリック／タップ | 何も起きない。クリックできる見た目にはしない。 |

- 操作できるパーツは、タップ領域を 44px × 44px 以上とし、フォーカスリング（`--color-primary`）を出す。ホバーは補助の見た目に限る（ホバー専用の機能は置かない）。
- 操作できるパーツの `aria-label` は、機器名、現在の状態、押したときの結果を示す（例: 「間接照明 ON。押すと OFF にします」）。
- 電灯の `aria-label` は、機器名、現在の状態、押したときの結果を示す（例: 「電灯 OFF。押すと調光パターンを選んで点灯します」「電灯 ON。押すと調光パターンの変更または消灯ができます」）。
- 電灯の現在の明るさと色温度は、画面に表示しない（REQ-006）。調光パターンダイアログで選んだパターン名も、切替後の図には残さない。
- 状態を取得できなかった機器のパーツは、輪郭を破線にして薄く示し、「取得できません」と警告の記号を添える。このパーツは切り替えられない（現在の状態が分からないため）。
- 切り替え中のパーツは、「切替中…」の文言を示す。

**確認ダイアログ（玄関ドア）**

| 部品 | 説明 |
|------|------|
| 文面 | 施錠するときは「玄関ドアを施錠します。よろしいですか?」、開錠するときは「玄関ドアを開錠します。よろしいですか?」。開錠のときは、「開錠すると、玄関のドアが開けられる状態になります。」の一文を添える。 |
| 主ボタン | 「確定」。押すと切り替えを実行する。 |
| 副ボタン | 「キャンセル」。押すと状態を変えずに閉じる。 |

背景を押しても閉じない（`rules/15-ui-style.md`）。

**調光パターンダイアログ（電灯）**

電灯のパーツ、または一括切替の「電灯選択」から開く。

| 部品 | 説明 |
|------|------|
| 見出し | 「調光パターンを選択」。 |
| パターンの選択肢 | 4 つ（「全灯」「読書」「くつろぎ」「夜」）を、この順に縦に並べる。各選択肢は副ボタンで、パターン名と、明るさ・色温度の目安を Caption で添える（全灯: 明るさ 100・色温度 6200、読書: 80・5000、くつろぎ: 50・3000、夜: 10・2700）。押すと、そのパターンで実行して閉じる。機器の操作の結果は、ステータスに示す。 |
| 消灯 | 電灯のパーツから開いたとき、電灯が ON の場合だけ出す副ボタン「消灯」。押すと電灯を OFF にして閉じる。「電灯選択」から開いたときは出さない。 |
| 副ボタン | 「キャンセル」。閉じるアイコン（`icons/close.svg`）。何も実行せずに閉じる。 |

- 文字ラベルを持たせる（4 つのパターンは、アイコンでは区別できないため）。
- 背景を押しても閉じない。
- 実行中は、選択肢と「消灯」を無効にする。
- パターンの種類と値は固定（利用者は変更できない）。

**状態別の表示**

| 状態 | 表示内容 |
|------|----------|
| 初期 | 画面を開くと同時に状態を取得する。取得が終わるまで「読込中」を示す。取得後、部屋の図、取得日時、一括切替を示す。 |
| 読込中 | 部屋の図の領域の中央に「読み込み中…」。更新、一括切替、パーツの操作は無効。更新ボタンを押した場合も同じ（直前の図は残してよい）。 |
| 空 | なし（機器は 5 つで固定のため、空の状態は無い）。 |
| エラー | 全機器の取得に失敗したときは、図の領域の先頭に「状態を取得できませんでした。」（`--color-danger`）。操作は更新だけ有効。一部の機器だけ失敗したときは、図は表示し、失敗した機器のパーツに「取得できません」を示す。切り替えの失敗は、ステータスに一文で示し、図は元の状態のままにする。 |

### SCR-002: 定期実行

- パス: `/portal_room/schedules`
- 目的: 定期実行の定義を確認し、登録・変更・削除・有効／無効の切替をする。最終実行の結果を確認する。
- 対応 REQ: REQ-008〜REQ-010

**部品配置**

##### PC（768px 以上）

```
┌──────────────────────────────────────────────────┐
│ 定期実行                                   [新規]│
├────┬────────┬──────┬──────────┬──────────┬──────┤
│有効│実行条件│時刻  │実行内容  │最終実行  │操作  │
├────┴────────┴──────┴──────────┴──────────┴──────┤
│ 朝の読書灯                                       │  ← タイトル（付いているときだけ）
│ ○   毎日      07:00  電灯を ON（読書） …  ✎ 🗑  │  ← 本体の行
├─────────────────────────────────────────────────┤
│ ○   月・水    22:30  間接照明を OFF  …    ✎ 🗑  │  ← タイトルが無いものは、本体の行だけ
└─────────────────────────────────────────────────┘
│ ステータス（1 行）                               │
```

1 件を、最大 2 行で示す。**タイトルが付いているものは 2 行**（1 行目にタイトル、2 行目に本体）、**付いていないものは 1 行**（本体だけ）にする。行の高さは、そろえない。

| 領域 | 部品 | 説明 |
|------|------|------|
| 上 | 見出し | 「定期実行」。 |
| 上 | 主ボタン | 新規アイコン（`icons/new.svg`）。`aria-label` は「新規」。定期実行入力（登録）を開く。 |
| 本体 | 一覧 | ヘッダ行は固定し、本体だけスクロールする（ヘッダ行の列は、有効、実行条件、時刻、実行内容、最終実行、操作。「タイトル」の見出しは置かない）。行内の横スクロールはしない。1 件の 2 行（タイトルと本体の行）は、同じ件の一まとまりで、間に区切り線を入れない（区切り線は、件と件の間だけ）。無効の件は、2 行とも薄く示す。並びは、API が返す順のまま（表示順の小さいものから。表示順が付いていないものは末尾。同じ値のもの同士の並びは、決まっていない）。画面では並べ替えない。 |
| 一覧の列（本体の行） | 有効 | 有効／無効の切替。押すとその場で切り替える。状態は形と文言（「有効」「無効」）でも示す。無効の行は薄く示す。 |
| 一覧の行 | タイトル（1 行目） | 付いているタイトルを、行の全幅で、本体の行の上に示す（太字）。付いていないものは、この行を出さない（空の行も、見出しも置かない）。長くて全幅に収まらないときは、省略して示し、全文は `title` 属性と `aria-label` で示す。表示順の数は、一覧には出さない。 |
| 一覧の列（本体の行） | 実行条件 | 「毎日」。曜日の指定は、選んだ曜日を月曜から順に「月・水・金」のように示し、祝日の扱いと実行日の取り方を、続けて示す。祝日の扱いが「祝日も実行」なら曜日の後ろに「・祝日」（例: 「月・水・祝日」）、「祝日は実行しない」なら「（祝日を除く）」（例: 「月・火・水・木・金（祝日を除く）」）。実行日の取り方が「の前の日」なら末尾に「の前の日」、「の次の日」なら「の次の日」（例: 「月・火・水・木・金（祝日を除く）の前の日」）。「指定した曜日のみ」と「当日」は、何も付けない。 |
| 一覧の列（本体の行） | 時刻 | `HH:MM`。 |
| 一覧の列（本体の行） | 実行内容 | 一括切替は、その名称（屋内スピーカー選択、枕元スピーカー選択、電灯選択、間接照明選択、お出かけ）。機器の個別切替は、「間接照明を ON」「屋内スピーカーを OFF」のように、機器名と状態を示す。電灯を ON にする個別切替は、「電灯を ON（読書）」のように、調光パターンの名称を添える。 |
| 一覧の列（本体の行） | 最終実行 | 最後に実行した年月日時分と、結果（「成功」「一部失敗」「失敗」）。失敗が含まれるときは、失敗した機器の名称を併せて示す。未実行なら「未実行」。結果は色だけでなく、文言と記号でも区別する。 |
| 一覧の列（本体の行） | 操作 | 編集アイコン（`icons/edit.svg`、`aria-label` は「編集」）と削除アイコン（`icons/delete.svg`、`aria-label` は「削除」）。削除は右端。 |
| 下 | ステータス | 常に 1 行分の高さを確保する。成功は一文、失敗は一文（`--color-danger`）。 |

##### スマートフォン（768px 未満）

一覧は表ではなく、1 件 1 枚のカード（単一カラム）で示す。

| 領域 | 部品 | 説明 |
|------|------|------|
| 上 | 見出しと新規 | 見出し「定期実行」と、新規アイコン。 |
| 本体 | カード | タイトルが付いているものは、カードの先頭にタイトル（付いていないものは、この行を出さない）。次に、時刻と有効／無効の切替。続けて、実行条件と実行内容。最終実行（日時と結果）。末尾に編集アイコンと削除アイコン。並びは、PC と同じ（API が返す順のまま）。 |
| 下 | ステータス | PC と同じ。 |

**定期実行入力（モーダル）**

登録と変更で共通。新規のときは空（実行条件は未選択、有効は ON）、変更のときは現在の値を入れる。背景を押しても閉じない。

| 部品 | 説明 |
|------|------|
| 実行条件 | 2 択（毎日／曜日の指定）のラジオ。 |
| 曜日 | 実行条件が「曜日の指定」のときだけ出す。月・火・水・木・金・土・日の 7 つの切替チップ。1 つ以上を選ぶ。選択は色だけでなくチェックの記号でも示す。 |
| 祝日の扱い | 実行条件が「曜日の指定」のときだけ出す。3 択のラジオ。「指定した曜日のみ」（既定）、「祝日も実行」、「祝日は実行しない」。説明（Caption）に、「祝日も実行は、指定した曜日に加えて祝日にも実行します。祝日は実行しないは、指定した曜日のうち祝日を除きます。」を添える。 |
| 実行日の取り方 | 実行条件が「曜日の指定」のときだけ出す。3 択のラジオ。「当日」（既定）、「の前の日」、「の次の日」。説明（Caption）に、「上で決まる日に対して、実行する日を選びます。の前の日は前日、の次の日は翌日に実行します。」を添える。 |
| 時刻 | 時と分（`HH:MM`）の入力。日本標準時。 |
| 実行内容の種類 | 2 択（一括切替／機器の個別切替）のラジオ。新規のときは未選択。 |
| 一括切替 | 実行内容が「一括切替」のときだけ出す。5 種（屋内スピーカー選択、枕元スピーカー選択、電灯選択、間接照明選択、お出かけ）から 1 つを選ぶ。 |
| 機器 | 実行内容が「機器の個別切替」のときだけ出す。4 つ（電灯、間接照明、屋内スピーカー、枕元スピーカー）から 1 つを選ぶ。 |
| 状態 | 実行内容が「機器の個別切替」のときだけ出す。2 択（ON／OFF）のラジオ。 |
| 調光パターン | 機器が「電灯」で、状態が「ON」のときだけ出す。4 択（全灯、読書、くつろぎ、夜）のラジオ。「全灯」が既定。説明（Caption）に、各パターンの明るさと色温度の目安を添える。機器や状態を変えて条件に合わなくなったら、隠し、選択を破棄する。 |
| （共通） | 玄関ドアの施錠・開錠は、実行内容のどの選択肢にも含めない。 |
| タイトル | 1 行のテキスト入力。任意（空でよい）。50 文字まで（入力欄で 50 文字を超えて入れられない）。説明（Caption）に、「一覧で見分けるための名前です。付けなくてもかまいません。」を添える。変更のときは、付いているタイトルを入れる。空にして保存すると、タイトルを外す。 |
| 表示順 | 数値の入力。任意（空でよい）。0 以上 9999 以下の整数。説明（Caption）に、「一覧での並びです。小さい数が先に並びます。空にすると末尾に並びます。」を添える。変更のときは、付いている表示順を入れる。空にして保存すると、表示順を外す。 |
| 有効 | 有効／無効の切替。 |
| 主ボタン | 保存アイコン（`icons/check.svg`）。`aria-label` は「保存」。 |
| 副ボタン | 「キャンセル」。閉じるアイコン（`icons/close.svg`）。入力を破棄して閉じる。 |
| エラー | 入力が不正なとき、モーダルの先頭に一文（`--color-danger`）。保存はされない。確認は、実行条件 → 曜日 → 時刻 → 実行内容 → タイトル → 表示順の順で、最初の 1 件を示す（「実行条件を選択してください。」「曜日を 1 つ以上選択してください。」「時刻を HH:MM の形式で入力してください。」「実行内容を選択してください。」「一括切替を選択してください。」「機器を選択してください。」「状態（ON / OFF）を選択してください。」「タイトルは 50 文字以内で入力してください。」「表示順は 0 以上 9999 以下の整数で入力してください。」）。 |

**確認ダイアログ（削除）**

「この定期実行を削除します。よろしいですか?」。「確定」と「キャンセル」。背景を押しても閉じない。
