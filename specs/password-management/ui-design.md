## 画面詳細

### SCR-001: パスワード管理

**部品配置**

| 領域 | 部品 | 説明 |
|------|------|------|
| コンテンツ上部 | 検索欄 | プレースホルダ「検索」。タイトル・ユーザ名・サイトURL・メモを対象に、大文字小文字を区別しない部分一致で一覧を絞り込む。入力のたびに一覧を再取得する。 |
| コンテンツ上部 | 新規登録ボタン | 検索欄の右側に離して配置する。登録フォームを開く。 |
| コンテンツ | パスワードエントリ一覧 | タイトル・ユーザ名を列に持つ一覧。パスワードは一覧に出さない。行を選ぶと詳細表示を開く。0件のときは「データがありません」（検索中は「該当するデータがありません」）。 |
| 詳細表示（モーダル） | タイトル | 見出しとして表示する。 |
| 詳細表示（モーダル） | ユーザ名 | 値を表示する。コピーボタンを併置する。 |
| 詳細表示（モーダル） | パスワード | 既定はマスク表示（`••••••••` 相当）。表示切替ボタンで平文表示とマスク表示を切り替える。コピーボタンを併置する（マスク中でも実際の値をコピーする）。複数行のときはそのまま改行を保って表示する。 |
| 詳細表示（モーダル） | サイトURL | 設定されているときだけ、新しいタブで開けるリンクとして表示する。未設定のときは表示しない。 |
| 詳細表示（モーダル） | メモ | 設定されているときだけ、改行を保って表示する。未設定のときは表示しない。 |
| 詳細表示（モーダル） | 編集ボタン | 編集フォームを開く（現在の内容を初期値にする）。 |
| 詳細表示（モーダル） | 削除ボタン | 削除確認ダイアログを開く。 |
| 詳細表示（モーダル） | 閉じるボタン | 詳細表示を閉じ、一覧に戻る。 |
| 登録・編集フォーム（モーダル） | 入力項目 | タイトル、ユーザ名、パスワード（複数行入力可、表示切替ボタン付き）、サイトURL（任意）、メモ（任意）。保存・キャンセルの操作を持つ。 |
| 削除確認ダイアログ | 確認文言 | 対象のタイトルを示し、削除してよいか確認する。 |
| 削除確認ダイアログ | 操作 | 削除・キャンセル。 |

**文言（本機能固有）**

`rules/15-ui-style.md` の共通語彙に無い、本機能固有の操作ラベル。アイコンに対応する画像が無いため、次の操作はアイコンではなく文字ラベルのボタンとする（`rules/15-ui-style.md` の「対応するアイコンが無い操作は文字ラベルのボタンのままにする」の適用）。

| 語 | 用途 |
|------|------|
| 検索 | 検索欄のプレースホルダ |
| コピー | ユーザ名・パスワードの値をクリップボードへコピーするボタン（コピー直後は「コピー済」に変わり、数秒で戻る） |
| 表示 / 隠す | パスワードのマスク表示・平文表示を切り替えるボタン。マスク中は「表示」、平文表示中は「隠す」と出す |

**状態別の表示**

| 状態 | 表示内容 |
|------|----------|
| 初期 | 一覧取得を開始する。検索欄は空。 |
| 読込中 | 領域の中央に「読み込み中…」。操作は無効。 |
| 空 | 検索キーワードが無いときは「データがありません」。検索中で0件のときは「該当するデータがありません」。いずれも新規登録は可能。 |
| エラー | 対象領域の先頭にエラーメッセージ（内部理由は出さない）。未ログインは表示せずログイン画面へ進む。 |

新規登録・編集・削除の成功時は、対象領域の先頭に成功メッセージを数秒表示する。

パスワードエントリ一覧はページ全体をスクロールさせず、一覧本体だけスクロールする（`rules/15-ui-style.md` の前提に従う）。

## 画面遷移

単一画面のため、画面間の遷移はない。モーダルの開閉のみ。

| 画面 | 操作 | 結果 |
|------|------|------|
| SCR-001 | 一覧の行を選ぶ | 詳細表示を開く |
| SCR-001 | 新規登録ボタン | 登録フォームを開く（詳細表示は開かない） |
| SCR-001（詳細表示） | 編集ボタン | 詳細表示を閉じ、編集フォームを開く |
| SCR-001（詳細表示） | 削除ボタン | 詳細表示を閉じ、削除確認ダイアログを開く |
| SCR-001（詳細表示） | 閉じるボタン | 詳細表示を閉じ、一覧に戻る |
| SCR-001（登録・編集フォーム） | 保存 | 成功すれば一覧を更新してフォームを閉じる。失敗すればエラーを示し、フォームは残す。 |
| SCR-001（登録・編集フォーム） | キャンセル | 入力を捨ててフォームを閉じる。 |
| SCR-001（削除確認） | 削除 | 成功すれば一覧を更新してダイアログを閉じる。失敗すればエラーを示す。 |
| SCR-001（削除確認） | キャンセル | 何もせずダイアログを閉じる。 |
| いずれか | 開く | 未ログイン時はログイン画面 URL |
| いずれか | 戻る | メニュー画面 URL |
