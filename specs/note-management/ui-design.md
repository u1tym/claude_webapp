# note-management UI設計

> 色・余白・部品の見た目・共通の操作ラベル・画面分割・ナビは `rules/15-ui-style.md` に従う。
> 起動・モジュール構成は書かない → `design.md`
> API のパス・要求・応答・エラーは書かない → `api-design.md`
> テーブル定義と ER 図は書かない → `db-design.md`

## 画面一覧

パスは Vue Router のルート（公開 URL の基点は `/portal_note_management/`）。`design.md` の画面一覧と一致する。

| 画面ID | 画面名 | パス | 目的 |
|--------|--------|------|------|
| SCR-001 | ノート一覧 | `/` | フォルダとファイルのツリー。フォルダ・ファイルの作成・名前変更・移動・並び替え・削除・削除解除、削除済みの表示、PDF 出力するファイルの選択。ファイルを開く入口。 |
| SCR-002 | ファイル | `/files/:id` | ファイルのタイトル・所属フォルダ名と、パーツの表示。パーツの追加・編集・削除・削除解除・並び替え、削除済みのパーツの表示、過去世代のダウンロード、PDF 出力。 |

ログイン画面とメニュー画面は持たない。

## 共通の構成

### 殻（ヘッダ / ナビ / コンテンツ）

殻は `rules/15-ui-style.md` に従う（PC は左ナビ、768px 未満は下ナビ）。`--color-primary` は Blue `#6C9BFF` とする。

| 領域 | 部品 | 説明 |
|------|------|------|
| ヘッダ | 機能名 | 「ノート」。システム共通アイコンを添える。 |
| ヘッダ | 戻るボタン | `back` アイコン（`aria-label`「戻る」）。システム設定のメニュー画面 URL へ進む。 |
| ナビ | 項目 | 「ノート」（SCR-001）のみ。SCR-002 でも「ノート」を現在地にする。 |

- ナビ項目は文字ラベルとする（ノートを表す単色アイコンが `icons/` に無いため。`rules/15-ui-style.md` の「対応するアイコンが無い操作は文字ラベルのままにする」の適用）。
- 画面内の「戻る」（SCR-002 から SCR-001 へ）も `back` アイコンとする。ヘッダの戻る（メニューへ）と区別できるよう、画面内の戻るは、コンテンツ上部の見出しの左に置く。

### アイコンと文字ラベルのボタン

`icons/` にあるアイコンで表せる操作はアイコンのみのボタン（`aria-label` で意味を示す）とする。表せない操作、または近接する複数のボタンが同じアイコンになって区別できなくなる操作は、文字ラベルのボタンとする。

| 操作 | 表現 |
|------|------|
| 保存・登録・更新 | `check`（「保存」） |
| キャンセル・閉じる | `close`（「キャンセル」「閉じる」） |
| 上位画面へ戻る | `back`（「戻る」） |
| 名前の変更（フォルダ・ファイル）、パーツの編集 | `edit`（「名前変更」「編集」） |
| 削除（フォルダ・ファイル・パーツ・チェックリストのカテゴリと項目・画像のマーカー・行動予定の地点） | `delete`（対象を `aria-label` で示す。例「フォルダの削除」） |
| 編集モードの切り替え（SCR-001） | `edit`（「編集モード」。押している間は押下状態を示す） |
| フォルダ追加、ファイル追加、パーツを追加、カテゴリ追加、項目追加、地点を追加 | 同じ `plus` になり区別できなくなるため文字ラベル |
| 移動、上へ、下へ、削除解除、ダウンロード、PDF 出力、PDF に出力、除外、削除済みを表示 | 対応するアイコンが無いため文字ラベル |

### 共通の表示

- 確認ダイアログ・入力ダイアログ・パーツのダイアログ: 背景（オーバーレイ）を押しても閉じない。閉じる操作は、ダイアログ内の実行のボタンと、`close`（キャンセル・閉じる）のボタンだけ。
- 一覧・本体は、部品内でスクロールし、ページ全体はスクロールさせない。
- 成功時は、対象領域の先頭に成功メッセージを数秒表示する。失敗時は、対象領域の先頭にエラーメッセージ（内部理由を含まない一文）を表示する。ダイアログでの失敗は、ダイアログの先頭に示し、ダイアログは閉じない。
- 削除済みのものは、文字を淡い色にし、「削除済み」のバッジを添える（色だけで区別しない）。祖先が削除済みで表示されているだけのものは、「上位が削除済み」のバッジとする。
- 未ログイン（認証エラー）を受けたら、画面を表示せず、ログイン画面 URL へ進む。権限なしのときは、その旨を表示する。

## 画面詳細

### SCR-001: ノート一覧

**部品配置**

| 領域 | 部品 | 説明 |
|------|------|------|
| コンテンツ上部 | 見出し | 「ノート」。 |
| コンテンツ上部 | ツールバー | 「フォルダ追加」（ルートフォルダを作る）、`edit`（編集モードの切り替え）、「PDF 出力」（PDF 出力モードの切り替え）、「削除済みを表示」（チェックボックス）。編集モードと PDF 出力モードは、同時にはオンにできない（片方をオンにすると、もう片方は無効になる）。 |
| コンテンツ | ツリー | フォルダとファイルの入れ子の一覧（下記）。 |
| コンテンツ下部（PDF 出力モードのみ） | 出力パネル | 選択したファイルの一覧（下記）。 |
| 入力ダイアログ | 名前の入力 | フォルダ名・ファイルのタイトルの入力（作成・変更に用いる）。`check`（保存）、`close`（キャンセル）。 |
| 確認ダイアログ | 削除の確認 | 名前を示し、削除してよいか確認する。操作は「削除」、`close`（キャンセル）。 |
| 選択ダイアログ | 移動先の選択 | フォルダのツリー。フォルダの移動のときは「（ルート）」も選べ、自分自身と、その子孫のフォルダは選べない（無効表示）。ファイルの移動のときは、ルートは選べない。現在の親は選べない。`check`（決定）、`close`（キャンセル）。 |

**ツリーの行**

- フォルダの行: 開閉の切り替え（三角の表示。`aria-label`「開く」「閉じる」、`aria-expanded`）、フォルダ名（押すと、開閉を切り替える）。フォルダは、開くと、直下のフォルダ、続いてファイルを、それぞれ並び順に、字下げして表示する。
- ファイルの行: ファイルのタイトル（押すと SCR-002 へ進む）。
- 通常の状態の行の操作: フォルダの行に「フォルダ追加」（子フォルダ）と「ファイル追加」。ファイルの行には操作なし。
- 編集モードの行の操作: 「上へ」「下へ」（同じ親の中の、隣りの、削除されていない項目と入れ替える。先頭では「上へ」、末尾では「下へ」が無効）、`edit`（名前変更・タイトル変更）、「移動」、`delete`（削除）。削除済みの行には、名前変更・移動・並び替え・削除を出さない。
- 削除済みを表示したとき: 削除済みの行（上位が削除済みのものを含む）に、バッジを添える。自身が削除済みの行には、常に（編集モードでなくても）「削除解除」を出す。上位が削除済みなだけの行には、「削除解除」を出さない（上位を削除解除すると、元に戻る）。
- 削除済みのフォルダの中身も、開いて、ファイルの内容を見ることができる。

**状態別の表示**

| 状態 | 表示内容 |
|------|----------|
| 初期 | ルートフォルダの取得を開始する。 |
| 読込中 | ツリーの領域の中央に「読み込み中…」。操作は無効。フォルダを開いたときは、そのフォルダの行の下に「読み込み中…」。 |
| 空 | ルートフォルダがないとき、ツリーに「データがありません」。フォルダを開いて、中が空のときは、その下に「データがありません」。「フォルダ追加」は有効。 |
| エラー | 対象領域の先頭にエラーメッセージ。同名がある場合は、入力ダイアログの先頭に「同じ名前があります」（ファイルは「同じタイトルがあります」）。自分の中へは移動できない場合は、「自分の中には移動できません」。ほかの操作も、内部理由を出さない一文とする。 |

**PDF 出力モード**

- ファイルの行に、チェックボックスを出す（ファイルのタイトルを押しても切り替わる）。削除済みのファイル（上位が削除済みのものを含む）には、出さない。
- 出力パネルに、「出力するファイル（n 件）」の見出しと、選択した順の一覧（番号、フォルダ名、タイトル）を示す。各行に、「上へ」「下へ」（順の入れ替え）、「除外」。選択が 0 件のときは、「一覧からファイルを選択してください。」。
- 「ファイルごとに改ページ」のチェックボックス（既定はオン）。
- 「PDF に出力」（選択が 0 件のときは無効）。押すと、各ファイルを取得し、印刷用のレイアウトを組み立て、ブラウザの印刷ダイアログを開く。準備中は、ボタンに「準備中…」を示し、無効にする。取得に失敗したときは、出力パネルの先頭にエラーメッセージを示す。
- PDF 出力モードを閉じると、選択は破棄される。

### SCR-002: ファイル

**部品配置**

| 領域 | 部品 | 説明 |
|------|------|------|
| コンテンツ上部 | `back`・見出し | `back` で SCR-001 へ戻る。所属フォルダ名（補足）と、ファイルのタイトル（見出し）。 |
| コンテンツ上部 | ツールバー | 「削除済みのパーツを表示」（チェックボックス）、「PDF 出力」（このファイル 1 件の印刷）。 |
| コンテンツ上部 | 削除済みの案内 | ファイルが削除済み（上位が削除済みを含む）のときだけ、「このファイルは削除済みです。内容の表示だけできます。」を示す。この状態では、パーツの追加・編集・削除・並び替えの操作を出さない。 |
| コンテンツ | パーツの一覧 | パーツのカードを、並び順に、縦に並べる（下記）。 |
| コンテンツ下部 | 「パーツを追加」 | パーツの追加ダイアログを開く（削除済みのファイルでは出さない）。 |
| パーツのダイアログ | 表示・操作 | カードを押すと開く。パーツの表示と、操作（下記）。 |
| パーツの追加ダイアログ | 種別と入力 | 種別を選び、種別に応じた入力欄（下記）。`check`（保存）、`close`（キャンセル）。 |

**パーツのカード**

- 種別ごとの内容（下記）を、そのまま表示する。カード全体が押せて、パーツのダイアログを開く。
- 左に「上へ」「下へ」を置く（同じファイルの中の、隣りの、削除されていないパーツと入れ替える。先頭では「上へ」、末尾では「下へ」が無効。削除済みのファイルでは出さない）。削除済みのパーツ（削除済みを表示しているとき）は、バッジを添え、並び替えの対象にしない。
- 種別ごとの表示:

| 種別 | 表示 |
|------|------|
| テキスト | 本文を、改行を保って表示する。 |
| Markdown | 整形して表示する。 |
| TeX | 数式を組版して表示する。組版に失敗した部分は、ソースのまま表示する。 |
| URL | 文字列を、リンクとして表示する（http / https のものだけ、新しいタブで開く。それ以外は、リンクにせず、文字列のまま表示する）。 |
| 行動予定 | 地点（時刻・場所）と経由メモを、順に並べる。時刻は、単一時刻、または「到着〜出発」。経由メモの補足は、改行を保つ。 |
| チェックリスト | タイトル（空なら非表示）。カテゴリの見出し（無名カテゴリは、見出しなし）ごとに、項目とチェック状態（チェックボックス。この画面では、操作できない）。 |
| JPEG・PNG | タイトル（空なら非表示）、画像（倍率どおりの大きさ）、マーカー（画像の上のピンと、下の凡例）。 |
| バイナリ | ファイル名。 |

**パーツのダイアログ（表示・操作）**

- 上部に `close`（閉じる）。中央にパーツの表示（カードと同じ内容。画像・バイナリはファイル名と大きさ付き）。
- 操作: `edit`（編集）、`delete`（削除）、バイナリと画像は「ダウンロード」。削除済みのパーツでは、編集・削除を出さず、「削除解除」を出す。削除済みのファイルでは、編集・削除・削除解除を出さない（ダウンロードだけ）。
- 画像・バイナリの過去世代: 「過去の世代」の見出しの下に、世代番号・ファイル名・種別・保管の日時と、「ダウンロード」を一覧する。なければ、見出しごと出さない。
- 編集を押すと、同じダイアログの中が、種別に応じた編集の状態に切り替わる（下記）。`check`（保存）、`close`（キャンセル。表示へ戻る）。保存が成功したら、ダイアログを閉じ、ファイルを取得し直す。失敗したら、ダイアログの先頭にエラーを示し、入力は残す。チェックリストは、編集の状態でも、`close`（閉じる）だけを出す（操作のたびに保存されるため）。

**種別ごとの入力**（追加・編集で共通。追加のときは、種別の選択欄を先頭に置く）

| 種別 | 入力欄 |
|------|--------|
| テキスト・Markdown・TeX・URL | 複数行の入力欄（URL は 1 行の入力欄。プレースホルダ `https://...`）。Markdown・TeX は、入力欄の下に、プレビューを示す。空でも保存できる。 |
| 行動予定 | 地点 1（時刻・場所）。地点 2 以降は、「単一時刻」「到着・出発」の切り替えと、時刻または到着・出発、場所。地点の間に、経由メモ（1 行）と補足（複数行）。地点 2 以降は `delete`（地点の削除）、末尾に「地点を追加」。 |
| チェックリスト | 追加のときは、入力欄なし（「空のチェックリストを作成します。」）。編集は、下記の操作。 |
| JPEG・PNG | 「ファイルを選択」（登録では必須。編集では、選び直したときだけ差し替え）、選んだファイル名と大きさ、タイトル（任意）、表示倍率（%。25〜400、既定 100）、マーカーの操作（下記）。 |
| バイナリ | 「ファイルを選択」（登録では必須。編集では、選び直したときだけ差し替え）、選んだファイル名と大きさ。 |

- 編集のときも、種別を選び直せる（チェックリストのパーツでは、種別の選択欄を無効にする。ほかの種別から、チェックリストは選べない）。種別を、入力の形が異なる種別（画像・バイナリ・行動予定と、それ以外）へ変えたときは、入力欄が、その種別のものに切り替わり、本文は空になる（同じ形の種別の間は、本文を引き継ぐ）。画像・バイナリへ変えたときは、ファイルの選択が必須になる。
- 画像・バイナリのファイルは、選んだ時点で、10 MB を超えるときは、その旨を示して受け付けない。ファイルを選び直すまで、保存できない。
- 保存の前に、入力を検証する。失敗したときは、ダイアログの先頭に、理由がわかるメッセージ（例:「地点または経由メモのどれかを入力してください」「画像のファイルを選択してください」「表示倍率は 25〜400 の間で入力してください」）を示し、保存しない。

**画像のマーカーの操作**（画像の編集）

- 「配置するマーカー」の選択（「家」「番号」）。画像を押すと、押した位置に、選んだ種類のマーカーを置く。番号マーカーの番号は、置いたときに、使われていない最小の番号（1 から）が付く。マーカーは、100 個まで（超えるときは置けず、その旨を示す）。
- 置いたマーカー（ピン）は、ドラッグして移動できる（押して選び、ドラッグ）。ピンを押すと、選択状態（枠で示す）になる。
- 画像の下に、凡例を示す。1 行に、マーカーの記号（家、または番号）、文字の入力欄（「説明を入力」）、`delete`（マーカーの削除）。
- 画像の表示の大きさは、指定した倍率に従う（プレビューにも反映する）。

**チェックリストの編集**（ダイアログの中。操作のたびに保存し、応答の状態で、表示を更新する）

- タイトルの入力欄（入力欄を離れたとき、または Enter で保存。変わっていなければ送らない）。
- カテゴリごとのブロック。無名カテゴリは、見出しなしで、先頭に置く（項目があるときだけ表示）。名前のあるカテゴリは、名前の入力欄（離れたとき、または Enter で保存）、「上へ」「下へ」、`delete`（カテゴリの削除。中の項目も削除される旨を、確認ダイアログで示す）。
- 項目の行: チェックボックス（編集の状態なので、操作できる）、タイトルの入力欄（離れたとき、または Enter で保存）、「上へ」「下へ」（カテゴリの中の順）、移動先のカテゴリの選択欄（選び直すと、そのカテゴリの末尾へ移す）、`delete`（項目の削除）。
- 各カテゴリ（無名を含む）の末尾に、項目のタイトルの入力欄と、「項目を追加」。一番下に、カテゴリ名の入力欄と、「カテゴリを追加」。
- ドラッグ操作: カテゴリのブロックと項目の行は、ドラッグして、順を入れ替えられる。項目は、別のカテゴリのブロックの上へも、ドラッグして移せる。ドラッグ中は、置ける位置を強調して示す。ドラッグを使えない環境でも、「上へ」「下へ」と、移動先の選択欄で、同じことができる。
- 失敗（同名のカテゴリなど）は、ダイアログの先頭にエラーを示す（「同じ名前のカテゴリがあります」）。

**状態別の表示**

| 状態 | 表示内容 |
|------|----------|
| 初期 | ファイルの取得を開始する。 |
| 読込中 | コンテンツの中央に「読み込み中…」。操作は無効。 |
| 空 | パーツがないとき、一覧に「データがありません」。「パーツを追加」は有効。 |
| エラー | 対象領域の先頭にエラーメッセージ。ファイルが存在しない、または他ユーザのものは、「ファイルが見つかりません」とし、SCR-001 へ戻れる。パーツの操作の失敗は、ダイアログの先頭にエラーを示す（並び替え・削除解除など、ダイアログを介さないものは、一覧の先頭に示す）。 |

パーツを追加・編集・削除・削除解除・並び替えしたときは、ファイルを取得し直して、一覧を更新する。

### PDF 出力（印刷用のレイアウト）

- 画面には表示しない領域に、印刷用のレイアウトを組み立て、印刷ダイアログを開く。印刷中は、殻（ヘッダ・ナビ）と、画面の操作を、出力から外す（印刷用のスタイル）。
- 1 ファイルごとに、フォルダ名（補足）、ファイルのタイトル（見出し）、削除されていないパーツを、並び順に、画面のカードと同じ内容で並べる。ただし、操作のボタンや、チェックリストの入力欄は出さず、表示だけにする。バイナリは、ファイル名と大きさだけを示す。
- 複数のファイルのときは、選んだ順に連結する。「ファイルごとに改ページ」がオンのとき、ファイルの前で改ページする。
- 画像の読み込みが終わってから、印刷ダイアログを開く。

## 画面遷移

| 画面 | 操作 | 遷移先 |
|------|------|--------|
| 共通 | 開く（未ログイン） | ログイン画面 URL |
| 共通 | ヘッダの戻る | メニュー画面 URL |
| 共通 | ナビ「ノート」 | SCR-001 |
| SCR-001 | ファイルの行 | SCR-002 |
| SCR-001 | PDF に出力 | ブラウザの印刷ダイアログ（画面は変わらない） |
| SCR-002 | 戻る | SCR-001 |
| SCR-002 | PDF 出力 | ブラウザの印刷ダイアログ（画面は変わらない） |

- モーダル（名前の入力、削除の確認、移動先の選択、パーツの追加、パーツの操作・編集）は、保存・実行（成功）またはキャンセル・閉じるで閉じる。保存・実行が失敗したときは、ダイアログは閉じずにエラーを示す。
- SCR-001 のツリーの展開の状態（開いているフォルダ）と、「削除済みを表示」の状態は、SCR-002 から戻ったとき、戻る前のまま保つ（ブラウザの再読み込みをしたときは、初期の状態に戻る）。戻ったときは、開いているフォルダの中身を、取得し直す。

## レイアウトの違い（PC とスマートフォン）

`rules/31-web-app-responsive-layout-spec.md` に従い、業務ロジックは共通、配置だけを変える。

| 画面 | PC（768px 以上） | スマートフォン（768px 未満） |
|------|-------------------|------------------------------|
| 共通 | 左ナビ | 下ナビ（1 項目） |
| SCR-001 | ツリーは、幅を制限した 1 カラム。行の操作は、行の右側に横並び。 | 同じツリーを 1 カラムで表示。行の操作は、次の行に回す（行の操作が多いときは折り返す）。ツールバーは折り返す。 |
| SCR-001（PDF 出力） | ツリーの下に出力パネル | 同じ順で 1 カラム |
| SCR-002 | パーツのカードは、幅を制限した 1 カラム。 | 1 カラム。画像は、画面の幅に収まる。 |
| ダイアログ | 中央に、幅を制限して表示。中身は、ダイアログの中でスクロール。 | 画面の幅に近い大きさ。中身は、ダイアログの中でスクロール。 |
| 行動予定・チェックリストの編集 | 入力欄を縦に並べ、幅を制限する。 | 同じ順で 1 カラム。 |

- ページ全体はスクロールさせない。ツリー・パーツの一覧・ダイアログの中身は、部品内でスクロールしてよい。
- 主なタップ領域は 44px × 44px 以上とする。
- マウスの hover を、操作の条件にしない。ドラッグ操作には、ボタンによる同じ操作の代わりを用意する。
