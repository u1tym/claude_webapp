# expense-management 要件定義

## 概要

家庭の家計管理を行うユーザ向けに、予算期間ごとの予算項目管理、支出方法（引き落とし条件）管理、日々の支出記録、および予算に対する実績の集計を行う機能である。ログインしたユーザ本人の家計データのみを扱う。

## 用語

| 用語 | 説明 |
|------|------|
| 予算期間 | 予算を管理する任意の期間（開始日〜終了日）。タイトルを持つ。ユーザが自由に設定する。同一ユーザ内で期間が重なる予算期間を複数作成できる。 |
| 予算項目 | 予算期間ごとに設定する支出のカテゴリ。項目名・金額・表示順を持つ。 |
| 支出方法 | 支出の決済手段。名称・締め日・支払月オフセット・支払日・ずらし方向・除外条件・表示順を持つ。 |
| 締め日 | 支出方法において、毎月何日に利用分を締めるかを表す基準値。0は即時支払を表す。 |
| 除外条件 | 支出方法に複数設定できる、実際の締め日または実際の支払日をずらす対象となる条件。「特定の曜日」「当月に存在しない日」または「祝日」のいずれかを条件種別とする。締め日用と支払日用をそれぞれ別に持つ。 |
| 祝日 | 日本の国民の祝日。ユーザは登録・編集せず、システムが日付から判定する。 |
| ずらし方向 | 支出方法ごとに、締め日用・支払日用それぞれ1つ設定する値。除外条件に該当したとき、過去方向・未来方向のどちらにずらすかを表す。 |
| 実際の締め日 | 締め日（基準値）に、締め日用の除外条件とずらし方向を適用して算出した、当月における実際の締め日。除外条件のいずれにも一致しなくなるまで、ずらし方向に従って1日ずつずらして決定する。 |
| 支払月オフセット | 実際の締め日から数えて何か月後に支払いが発生するかを表す値。 |
| 支払日 | 支払いが発生する日（何日）を表す基準値。 |
| 実際の支払日 | 支払日（基準値）に、支払日用の除外条件とずらし方向を適用して算出した、対象月における実際の支払日。算出方法は実際の締め日と同様。 |
| 支出記録 | 実際に発生した支出の記録。利用日・予算区分・用途・金額・支出方法・メモ・入力日・支払日・削除フラグを持つ。 |
| 削除フラグ | 支出記録を削除したことを表す値。削除してもデータは残し、以降の一覧表示・集計の対象外とする。 |
| 用途 | 支出記録に付与する、支出内容を表す自由記述の文字列（例:「ランチ代」）。 |
| 予算区分 | 支出記録が属する予算項目。支出記録の登録時にユーザが予算項目の中から選択する。 |
| 支払発生月 | 支出記録の利用日と、選択された支出方法の実際の締め日・支払月オフセット・実際の支払日から算出される、実際に支払いが発生する年月。 |

## 要件一覧

### REQ-001: 予算期間の新規作成

ユーザが予算期間を新規作成するとき、システムはタイトルと開始日と終了日を受け付けて予算期間を登録すること。

**受け入れ条件**

- タイトル・開始日・終了日を入力して予算期間を新規作成できる
- 終了日が開始日より前の場合、システムは登録を拒否する
- 入力された期間が、同一ユーザの既存の予算期間と重なっていても登録できる

### REQ-002: 予算期間の複製作成

ユーザが直近の予算期間を引用して新しい予算期間を作成するとき、システムはタイトルと開始日と終了日を受け付けて予算期間を登録し、直近の予算期間に属する予算項目（項目名・金額・表示順）を複製して新しい予算期間の予算項目として登録すること。

**受け入れ条件**

- 直近の予算期間を選択し、新しいタイトル・開始日・終了日を入力して、その予算項目一覧を複製した新しい予算期間を作成できる
- 複製後の予算項目は、個別に金額・項目名・表示順を編集できる
- 新しい予算期間の期間が、同一ユーザの既存の予算期間と重なっていても作成できる

### REQ-003: 予算項目の登録・編集・削除

ユーザが予算期間に対して予算項目を登録・編集・削除するとき、システムは項目名・金額・表示順を保持すること。

**受け入れ条件**

- 予算期間内に、項目名・金額・表示順を入力して予算項目を追加できる
- 既存の予算項目の項目名・金額・表示順を編集できる
- 予算項目を削除できる

### REQ-004: 予算期間・予算項目の一覧表示

システムは常に、登録済みの予算期間と、各予算期間に属する予算項目を一覧表示すること。

**受け入れ条件**

- 予算期間の一覧を、タイトルとともに表示できる
- 予算期間を選択すると、その予算項目が表示順に並んで表示される

### REQ-005: 支出方法の登録

ユーザが支出方法を登録するとき、システムは名称・締め日・支払月オフセット・支払日・ずらし方向・除外条件・表示順を受け付けること。

**受け入れ条件**

- 名称、締め日（0〜31の範囲）、支払月オフセット、支払日、表示順を入力して支出方法を登録できる
- 締め日に0を指定した場合、システムは支払月オフセットおよび支払日の入力を求めず、即時支払を表す固定値を自動設定する
- 締め日が1以上の場合、締め日用のずらし方向（過去または未来）を1つ選択できる
- 締め日が1以上の場合、締め日用の除外条件を0件以上登録できる。除外条件は「特定の曜日」「当月に存在しない日」または「祝日」のいずれかを条件種別とする。「特定の曜日」を選ぶ場合は対象の曜日を指定する
- 締め日が1以上の場合、支払日用のずらし方向（過去または未来）を1つ選択できる
- 締め日が1以上の場合、支払日用の除外条件を0件以上登録できる。条件種別は締め日用と同様とする

### REQ-006: 支出方法の編集・削除

ユーザが登録済みの支出方法を編集・削除するとき、システムはその内容を更新または削除すること。

**受け入れ条件**

- 名称・締め日・支払月オフセット・支払日・締め日用と支払日用それぞれのずらし方向・除外条件・表示順を編集できる
- 締め日を0に変更した場合、支払月オフセットおよび支払日は即時支払を表す固定値に自動更新され、締め日用・支払日用のずらし方向および除外条件は保持しない
- 締め日を0以外に変更した場合、支払月オフセット・支払日・締め日用と支払日用それぞれのずらし方向・除外条件を入力できる
- 除外条件を追加・削除できる
- 支出方法を削除できる

### REQ-007: 支出方法の一覧表示

システムは常に、登録済みの支出方法（名称・締め日・支払月オフセット・支払日・表示順）を表示順に一覧表示すること。

**受け入れ条件**

- 支出方法の一覧を、名称・締め日・支払月オフセット・支払日とともに、表示順に並べて表示できる

### REQ-008: 支出記録の登録

ユーザが支出記録を登録するとき、システムは利用日・予算・予算区分・用途・金額・支出方法・メモを受け付け、入力日を自動的に記録すること。

**受け入れ条件**

- 利用日、予算（登録済みの予算期間、または「予算なし」から選択）、用途、金額、支出方法を入力して登録できる（メモは任意入力）
- 予算に予算期間を選んだときは、その予算期間の予算項目から予算区分を選択して登録する（必須）
- 予算に「予算なし」を選んだときは、予算区分は登録しない
- 入力日はシステムが自動的に記録し、ユーザは入力しない
- 支払日は、利用日と選択した支出方法の実際の締め日・支払月オフセット・実際の支払日（REQ-013）からシステムが自動算出し、初期値として設定する
- 支払日の自動算出は、ユーザが有効・無効を切り替えられる。既定は有効とする
- ユーザは、自動算出された支払日を手入力で修正できる

### REQ-009: 支出記録の編集・削除

ユーザが登録済みの支出記録を編集・削除するとき、システムはその内容を更新、または削除フラグを立てて削除すること。

**受け入れ条件**

- 利用日・予算・予算区分・用途・金額・支出方法・メモ・支払日を編集できる
- 予算は、登録済みの予算期間、または「予算なし」に変更できる。予算期間に変更したときは、その予算期間の予算項目から予算区分を選び直せる
- 予算を「予算なし」に変更すると、予算区分は未設定になる
- 支払日の自動算出が有効なとき、支出方法または利用日を変更した場合、システムは支払日を再算出して表示する
- 支払日の自動算出を無効にした場合、支出方法または利用日を変更しても支払日は再算出されない
- ユーザは、再算出された支払日を手入力で修正できる
- 支出記録を削除できる。削除しても記録は残り、削除フラグが立った状態になる

### REQ-010: 支出記録の一覧表示

システムは常に、削除フラグが立っていない支出記録を一覧表示すること。

**受け入れ条件**

- 支出記録の一覧を、利用日・予算区分・用途・金額・支出方法・支払日とともに表示できる
- 予算区分が無い（予算なし）支出記録は、予算区分が無いとわかるように表示する
- 削除フラグが立っている支出記録は一覧に表示されない

### REQ-011: 予算対実績の集計（利用日基準）

ユーザが予算期間を選択したとき、システムはその期間内の利用日を持つ、削除フラグが立っていない支出記録を予算項目ごとに集計し、予算金額と比較して表示すること。

**受け入れ条件**

- 予算期間を選択すると、予算項目ごとに予算金額・支出合計（利用日基準）・差額（予算金額-支出合計）が表示される
- 削除フラグが立っている支出記録は集計に含まない

### REQ-012: 予算対実績の集計（支払発生月基準）

ユーザが年月を選択したとき、システムはその支払発生月に該当する、削除フラグが立っていない支出記録を予算項目ごとに集計して表示すること。

**受け入れ条件**

- 年月を選択すると、予算項目ごとの支出合計（支払発生月基準）が表示される
- ユーザは、利用日基準の集計表示と支払発生月基準の集計表示を切り替えて確認できる
- 削除フラグが立っている支出記録は集計に含まない

### REQ-013: 実際の締め日・実際の支払日の算出

支出記録の支払日を算出するとき、システムは対象の支出方法の締め日（基準値）と支払日（基準値）のそれぞれに、対応する除外条件とずらし方向を適用して実際の締め日・実際の支払日を算出すること。

**受け入れ条件**

- 締め日が0の支出方法は、実際の締め日・実際の支払日の算出を行わず即時支払として扱う
- 実際の締め日（初期値は締め日と同じ）が、締め日用の除外条件のいずれにも一致しない場合、締め日をそのまま実際の締め日とする
- 実際の締め日が締め日用の除外条件（特定の曜日、当月に存在しない日、または祝日）のいずれかに一致する場合、締め日用のずらし方向に従って1日ずらし、いずれの除外条件にも一致しなくなるまでこれを繰り返す
- 実際の支払日（初期値は支払日と同じ）が、支払日用の除外条件のいずれにも一致しない場合、支払日をそのまま実際の支払日とする
- 実際の支払日が支払日用の除外条件のいずれかに一致する場合、支払日用のずらし方向に従って1日ずらし、いずれの除外条件にも一致しなくなるまでこれを繰り返す

### REQ-014: 予算期間の更新

ユーザが登録済みの予算期間を更新するとき、システムはタイトル・開始日・終了日を更新できること。

**受け入れ条件**

- 既存の予算期間のタイトル・開始日・終了日を編集できる
- 終了日が開始日より前の場合、システムは更新を拒否する
- 更新後の期間が、同一ユーザの既存の予算期間と重なっていても更新できる
- 存在しない、または本人以外の予算期間の更新は失敗する

## 認証の要否

本機能はログイン認証を必須とする。ログインしたユーザ本人が登録した予算期間・予算項目・支出方法・支出記録のみを参照・操作できる。

## スコープ外

- 予算項目・支出方法・支出記録以外の資産管理（口座残高、資産推移等）
- 他ユーザとの家計データの共有
- 金融機関・外部家計簿サービスとの連携
