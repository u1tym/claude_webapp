## 画面一覧

| 画面ID | 画面名 | パス | 目的 |
|--------|--------|------|------|
| SCR-001 | 支出記録 | `/portal_expense_management/` | 支出記録の一覧確認と登録・編集・削除 |
| SCR-002 | 予算管理 | `/portal_expense_management/budgets` | 予算期間と予算項目の管理 |

いずれの画面も `rules/15-ui-style.md` のヘッダ / ナビの殻を使う。ナビには 4 画面（支出記録・予算管理・支出方法管理・集計）を常時表示する。

## 画面詳細

### SCR-001: 支出記録

**部品配置**

| 領域 | 部品 | 説明 |
|------|------|------|
| コンテンツ上部 | 予算選択 | ラベル「予算」。選択肢は「すべて」と、直近の予算期間（開始日の新しい順）最大10件。既定は「すべて」。表示対象の絞り込みに使う（下記）。 |
| コンテンツ上部 | 新規登録ボタン | 予算選択の右側に離して配置する。支出記録の登録フォームを開く。 |
| コンテンツ | 支出記録一覧 | 利用日・予算区分・用途・金額・支出方法・支払日を列に持つ一覧。行ごとに編集・削除の操作を持つ。利用日の新しい順に並べる。予算選択の対象で絞り込む（下記）。 |
| フォーム（登録） | 予算期間選択 | 予算選択で「すべて」を選んでいるときだけ出す。未削除の予算期間から選ぶ。既定は直近の予算期間。ここで選んだ予算期間に属する予算項目が、次の予算区分の選択肢になる。予算選択で個別の予算期間を選んでいるときは出さず、その予算期間の予算項目を予算区分の選択肢とする。 |
| フォーム（登録・編集） | 入力項目 | 利用日、予算区分（予算項目からの選択）、用途（自由記述）、金額、支出方法（選択）、メモ（任意）、支払日（初期値は自動算出。手入力で修正可）。保存・キャンセルの操作を持つ。編集フォームでは予算期間選択は出さない（編集対象の支出記録が属する予算区分から予算期間を判定し、その予算項目を予算区分の選択肢とする）。 |
| フォーム（登録・編集） | 支払日の自動算出チェックボックス | 支払日の右側に置く。既定はオン。オンのとき、利用日または支出方法の変更に応じて支払日を再算出する。オフにすると再算出しない（支払日は手入力のみで変わる）。 |
| フォーム（登録・編集） | 削除ボタン | 編集フォームから、対象の支出記録を削除する（確認あり）。 |

**絞り込み**

| 予算選択 | 一覧・新規登録の予算区分の対象 |
|------|------|
| すべて | 利用日が現在日付の3か月前以降の支出記録（未来方向の上限は無い） |
| 個別の予算期間 | その予算期間の開始日〜終了日の範囲の支出記録 |

**状態別の表示**

| 状態 | 表示内容 |
|------|----------|
| 初期 | 予算選択「すべて」の状態で、現在日付の3か月前以降（未来方向の上限は無い）の支出記録一覧を表示する |
| 読込中 | 一覧領域の中央に「読み込み中…」を表示し、操作を無効にする |
| 空 | 一覧本体に「データがありません」を表示する |
| エラー | 一覧領域の先頭にエラーメッセージを表示する。フォームでの保存失敗時はフォーム先頭にエラーメッセージを表示する |

### SCR-002: 予算管理

SCR-002 は「一覧表示」と「詳細表示」の2つの表示状態を切り替える単一画面とする（画面遷移（パス）は増やさない）。初期表示は一覧表示とする。一覧表示で予算期間を選ぶと詳細表示に切り替わる。詳細表示の「戻る」で一覧表示に戻る。

**部品配置（一覧表示）**

| 領域 | 部品 | 説明 |
|------|------|------|
| コンテンツ上部 | 新規作成ボタン | タイトル・開始日・終了日を入力する予算期間の新規作成フォームを開く。 |
| コンテンツ上部 | 複製作成ボタン | 直近の予算期間の予算項目を複製し、タイトル・開始日・終了日を入力して新しい予算期間を作成するフォームを開く。 |
| コンテンツ | 予算期間一覧 | 画面幅いっぱいに、タイトルと開始日〜終了日を表示する。行を選ぶと、その予算期間の詳細表示に切り替わる。 |
| フォーム（予算期間の新規作成・複製作成） | 入力項目 | タイトル、開始日、終了日。保存・キャンセルの操作を持つ。既存の予算期間と重なっていても保存できる。保存に成功すると、作成した予算期間の詳細表示に切り替わる。 |

**部品配置（詳細表示）**

| 領域 | 部品 | 説明 |
|------|------|------|
| コンテンツ上部 | 戻るボタン | 一覧表示に戻る。 |
| コンテンツ | 予算期間編集フォーム | 選択中の予算期間のタイトル・開始日・終了日を編集する入力欄。保存・キャンセルの操作を持つ。保存は詳細表示のまま内容を更新する（一覧表示には戻らない）。キャンセルは入力を直前に保存された値に戻す（詳細表示のまま、一覧表示には戻らない）。既存の予算期間と重なっていても保存できる。 |
| コンテンツ | 予算項目一覧 | 選択中の予算期間に属する予算項目（項目名・金額・表示順）を表示順に一覧表示する。行ごとに編集・削除の操作を持つ。 |
| コンテンツ | 予算項目追加ボタン | 選択中の予算期間へ、項目名・金額・表示順を入力する予算項目の登録フォームを開く。 |
| フォーム（予算項目の登録・編集） | 入力項目 | 項目名、金額、表示順。保存・キャンセルの操作を持つ。 |

**状態別の表示**

| 状態 | 表示内容 |
|------|----------|
| 初期 | 一覧表示。予算期間一覧を取得して表示する |
| 読込中 | 一覧領域の中央に「読み込み中…」を表示し、操作を無効にする |
| 空 | 予算期間が1件も無いときは一覧表示の予算期間一覧に「データがありません」を表示する。詳細表示で予算項目が0件のときは予算項目一覧に「データがありません」を表示する |
| エラー | 対象領域の先頭にエラーメッセージを表示する。登録・更新失敗時はフォーム先頭にエラーメッセージを表示する |

### SCR-003: 支出方法管理

**部品配置**

| 領域 | 部品 | 説明 |
|------|------|------|
| コンテンツ上部 | 新規登録ボタン | 支出方法の登録フォームを開く。 |
| コンテンツ | 支出方法一覧 | 名称・締め日・支払月オフセット・支払日・ずらし方向・除外条件の件数を表示順に一覧表示する。行ごとに編集・削除の操作を持つ。 |
| フォーム（登録・編集） | 基本項目 | 名称、締め日（0〜31）、表示順。締め日に0を指定すると、以降の項目は非表示にする。 |
| フォーム（登録・編集） | 締め日1以上のときの項目 | 支払月オフセット、支払日、ずらし方向（過去／未来）。 |
| フォーム（登録・編集） | 除外条件一覧 | 条件種別（特定の曜日／当月に存在しない日／祝日）と、曜日を選ぶ場合の対象曜日を表示する。追加・削除の操作を持つ。 |
| フォーム（登録・編集） | 保存・キャンセル・削除 | 保存・キャンセルの操作を持つ。編集時は削除ボタンも持つ（確認あり）。 |

登録・編集フォームは、項目数が多いため画面幅を広く使う（ウィンドウ幅の8割程度）。

**状態別の表示**

| 状態 | 表示内容 |
|------|----------|
| 初期 | 登録済みの支出方法一覧を表示順に表示する |
| 読込中 | 一覧領域の中央に「読み込み中…」を表示し、操作を無効にする |
| 空 | 一覧本体に「データがありません」を表示する |
| エラー | 一覧領域の先頭にエラーメッセージを表示する。フォームでの保存失敗時はフォーム先頭にエラーメッセージを表示する |

### SCR-004: 集計

**部品配置**

| 領域 | 部品 | 説明 |
|------|------|------|
| コンテンツ上部 | 集計基準切替 | 「利用日基準」「支払発生月基準」を切り替える。 |
| コンテンツ上部（利用日基準） | 予算期間選択 | 集計対象の予算期間をタイトルで選ぶ。 |
| コンテンツ上部（支払発生月基準） | 年月選択 | 集計対象の年月を選ぶ。 |
| コンテンツ | 集計一覧 | 予算項目ごとに、予算金額・支出合計・差額（利用日基準）、または支出合計（支払発生月基準）を一覧表示する。 |

**状態別の表示**

| 状態 | 表示内容 |
|------|----------|
| 初期 | 利用日基準、既定の予算期間を選択した状態で集計結果を表示する |
| 読込中 | 一覧領域の中央に「読み込み中…」を表示する |
| 空 | 対象の予算項目が無いときは「データがありません」を表示する |
| エラー | 一覧領域の先頭にエラーメッセージを表示する |
