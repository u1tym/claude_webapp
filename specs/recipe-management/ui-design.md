# recipe-management UI設計

> 色・余白・部品の見た目・共通の操作ラベル・画面分割・ナビは `rules/15-ui-style.md` に従う。
> 起動・モジュール構成は書かない → `design.md`
> API のパス・要求・応答・エラーは書かない → `api-design.md`
> テーブル定義と ER 図は書かない → `db-design.md`

## 画面一覧

パスは Vue Router のルート（公開 URL の基点は `/portal_recipe_management/`）。`design.md` の画面一覧と一致する。

| 画面ID | 画面名 | パス | 目的 |
|--------|--------|------|------|
| SCR-001 | レシピ一覧 | `/` | 本人のレシピを、かなの順に表示する。詳細・登録への入口。 |
| SCR-002 | レシピ登録 | `/recipes/new` | メニュー名・かな・工程・材料と分量の入力。材料・分量名称の追加。 |
| SCR-003 | レシピ詳細 | `/recipes/:id` | メニュー名・かな・材料一覧・工程ごとの説明と材料の表示。編集・削除への入口。 |
| SCR-004 | レシピ編集 | `/recipes/:id/edit` | 登録と同じ入力を、現在の内容を初期値として編集する。 |

ログイン画面とメニュー画面は持たない。

## 共通の構成

### 殻（ヘッダ / ナビ / コンテンツ）

殻は `rules/15-ui-style.md` に従う（PC は左ナビ、768px 未満は下ナビ）。`--color-primary` は Orange `#FFA36C` とする。

| 領域 | 部品 | 説明 |
|------|------|------|
| ヘッダ | 機能名 | 「レシピ」。システム共通アイコンを添える。 |
| ヘッダ | 戻るボタン | `back` アイコン（`aria-label`「戻る」）。システム設定のメニュー画面 URL へ進む。 |
| ナビ | 項目 | 「レシピ」（SCR-001）のみ。SCR-002〜004 でも、「レシピ」を現在地にする。 |

- ナビ項目は文字ラベルとする（レシピを表す単色アイコンが `icons/` に無いため。`rules/15-ui-style.md` の「対応するアイコンが無い操作は文字ラベルのままにする」の適用）。

### アイコンと文字ラベルのボタン

`icons/` にあるアイコンで表せる操作はアイコンのみのボタン（`aria-label` で意味を示す）とする。表せない操作は文字ラベルのボタンとする。

| 操作 | 表現 |
|------|------|
| 新規（レシピの登録の入口） | `plus`（`aria-label`「新規」） |
| 編集 | `edit`（「編集」） |
| 削除（レシピ、手順、材料の行） | `delete`（「削除」） |
| 保存・登録・更新 | `check`（「保存」） |
| キャンセル・閉じる | `close`（「キャンセル」「閉じる」） |
| 上位画面へ戻る | `back`（「戻る」） |
| 材料・分量名称の新規登録（入力欄の横） | `plus`（「材料の新規登録」「分量名称の新規登録」） |
| 手順を追加、材料を追加 | 対応するアイコンが無いため文字ラベル |

### 共通の表示

- 分量の表示: 数量ありの分量名称は「接頭語＋数量＋接尾語」（例: 「大さじ1」「200g」）、数量なしは「接頭語＋接尾語」（例: 「少々」）。
- 確認ダイアログ・入力ダイアログ: 背景（オーバーレイ）を押しても閉じない。閉じる操作は、ダイアログ内の実行のボタンと、`close`（キャンセル）のボタンだけ。
- 一覧・本体は、部品内でスクロールし、ページ全体はスクロールさせない。
- 成功時は、対象領域の先頭に成功メッセージを数秒表示する。失敗時は、対象領域の先頭にエラーメッセージ（内部理由を含まない一文）を表示する。
- 未ログイン（認証エラー）を受けたら、画面を表示せず、ログイン画面 URL へ進む。権限なしのときは、その旨を表示する。

## 画面詳細

### SCR-001: レシピ一覧

**部品配置**

| 領域 | 部品 | 説明 |
|------|------|------|
| コンテンツ上部 | 見出し・新規ボタン | 見出し「レシピ」。`plus`（新規）で SCR-002 へ進む。 |
| コンテンツ | レシピ一覧 | 1 行に、メニュー名とかなを表示する。かなの昇順（同じなら登録の古い順）。行を押すと SCR-003 へ進む。 |

**状態別の表示**

| 状態 | 表示内容 |
|------|----------|
| 初期 | 一覧の取得を開始する。 |
| 読込中 | 一覧の領域の中央に「読み込み中…」。操作は無効。 |
| 空 | 一覧に「データがありません」。新規ボタンは有効。 |
| エラー | 対象領域の先頭にエラーメッセージ。新規ボタンは有効。 |

### SCR-002: レシピ登録

**部品配置**（SCR-004 と同じ入力フォームを用いる）

| 領域 | 部品 | 説明 |
|------|------|------|
| コンテンツ上部 | 見出し・`back` | 見出し「レシピ登録」。`back` で SCR-001 へ戻る（保存中は無効）。 |
| フォーム「メニュー」 | メニュー名 | 必須。 |
| フォーム「メニュー」 | かな | 必須。 |
| フォーム「手順 n」 | 見出し・削除 | 見出し「手順 n」（n は 1 からの番号）。`delete`（手順の削除）は、手順が 2 件以上あるときだけ有効。 |
| フォーム「手順 n」 | 材料の行（0 件以上） | 見出し「材料 m」と `delete`（行の削除）。下の項目を持つ。 |
| 材料の行 | 材料 | 選択欄（「-- 選択してください --」が初期）。選択肢は「名前（かな）」で、独自のものには「（独自）」を添える。かなの昇順。横に `plus`（材料の新規登録。材料の追加ダイアログを開く）。 |
| 材料の行 | 分量 | 接頭語の選択欄、数量の入力欄、接尾語の選択欄を横に並べる。接頭語の選択肢は、分量名称の接頭語の重複を除いた一覧（空は「（空）」）。接尾語の選択肢は、選んだ接頭語と組になる接尾語（空は「（空）」）。接頭語を選び直すと、接尾語は、その先頭の組にそろえる。横に `plus`（分量名称の新規登録。分量名称の追加ダイアログを開く）。 |
| 材料の行 | 数量 | 選んだ分量名称が数量ありのときだけ入力でき、必須。数量なしのときは、入力できず、空になる。 |
| フォーム「手順 n」 | 「材料を追加」ボタン | 材料の行を末尾に加える。 |
| フォーム「手順 n」 | 手順説明 | 複数行、必須。 |
| フォーム下部 | 「手順を追加」ボタン | 手順を末尾に加える。 |
| フォーム下部 | 操作 | `check`（保存）、`close`（キャンセル。SCR-001 へ戻る）。保存中は、どちらも無効にする。 |
| 材料の追加ダイアログ（モーダル） | 入力項目 | 材料名（必須）、かな（必須）。`check`（保存）、`close`（キャンセル）。保存が成功したら、ダイアログを閉じ、選択肢を取得し直し、開いた行の材料として、追加した材料を選ぶ。 |
| 分量名称の追加ダイアログ（モーダル） | 入力項目 | 接頭語、接尾語（どちらかは必須）、「数量が必要」のチェック（既定はオン）。`check`（保存）、`close`（キャンセル）。保存が成功したら、ダイアログを閉じ、選択肢を取得し直し、開いた行の分量名称として、追加したものを選ぶ（数量が必要なときは、数量の既定は「1」）。 |

- 手順は、最初から 1 件あり、その中に、材料の行が 1 件ある。手順・材料の行を追加したときの、分量名称は、分量名称の先頭のもの（接頭語の昇順、同じなら接尾語の昇順）が選ばれた状態にする。
- 材料が未選択の行は、保存のときに、取り除く（検証の対象にしない）。
- 保存の前に、入力を検証する。メニュー名・かなが空、手順の説明が空、材料を選んだ行の分量名称が未選択、数量が必要なのに数量が空、のときは、フォームの先頭に、何番目の手順・材料かがわかるエラーメッセージ（例: 「手順 2・材料 1: 数量を入力してください」）を示し、保存しない。

**状態別の表示**

| 状態 | 表示内容 |
|------|----------|
| 初期 | 材料と分量名称の選択肢の取得を開始する。入力欄は空。 |
| 読込中 | 選択肢の取得中は、フォームの位置に「選択肢を準備中…」。保存中は、フォーム全体を無効にする。 |
| 空 | 材料・分量名称の選択肢が無いときは、その選択欄に「データがありません」。新規登録のダイアログから追加できる。 |
| エラー | フォームの先頭にエラーメッセージ（同名のレシピがあるときは「同じメニュー名のレシピがあります」など、内部理由は出さない）。入力内容は残す。ダイアログのエラーは、ダイアログの先頭に示す（同名の材料・分量名称があるときは「同じ名前の材料があります」「同じ分量名称があります」）。 |

保存が成功したら、成功メッセージを示さず、登録したレシピの SCR-003 へ進む。

### SCR-003: レシピ詳細

**部品配置**

| 領域 | 部品 | 説明 |
|------|------|------|
| コンテンツ上部 | `back`・メニュー名 | `back` で SCR-001 へ戻る。メニュー名を見出しにし、かなを添える。 |
| コンテンツ上部 | 操作 | `edit`（編集。SCR-004 へ進む）、`delete`（削除。確認ダイアログを開く）。 |
| コンテンツ | 材料一覧 | 全工程の材料を、工程の順、工程内の並びの順に、材料名と分量の表示を並べる。材料が 1 件も無いレシピでは、この部分を表示しない。 |
| コンテンツ | 手順 | 工程番号の昇順に、1 つの手順を 1 枚のカードで示す。カードに、「手順 n」、説明、その手順の材料（材料名と分量の表示）を並べる。 |
| 確認ダイアログ | 削除の確認 | メニュー名を示し、削除してよいか確認する。操作は「削除」、`close`（キャンセル）。 |

**状態別の表示**

| 状態 | 表示内容 |
|------|----------|
| 初期 | レシピの取得を開始する。 |
| 読込中 | 領域の中央に「読み込み中…」。操作は無効。 |
| 空 | 手順に材料が無いときは、その手順のカードに材料を示さない（説明だけ）。 |
| エラー | 対象領域の先頭にエラーメッセージ。レシピが存在しない、削除済み、または他ユーザのものは、「レシピが見つかりません」とし、SCR-001 へ戻れる。削除に失敗したときは、ダイアログを閉じ、エラーメッセージを示す。 |

削除が成功したら、SCR-001 へ進む（成功メッセージを数秒示す）。

### SCR-004: レシピ編集

**部品配置**

SCR-002 と同じ入力フォームを用いる。違いは次のとおり。

| 領域 | 部品 | 説明 |
|------|------|------|
| コンテンツ上部 | 見出し・`back` | 見出し「レシピ編集」。`back` で SCR-003 へ戻る（保存中は無効）。 |
| フォーム | 初期値 | 現在のメニュー名・かな・工程・材料の行が入った状態。材料の行の材料・分量名称・数量も、現在の値が選ばれた状態。 |
| フォーム下部 | 操作 | `check`（保存）、`close`（キャンセル。SCR-003 へ戻る）。 |

**状態別の表示**

| 状態 | 表示内容 |
|------|----------|
| 初期 | レシピと、材料・分量名称の選択肢の取得を開始する。 |
| 読込中 | フォームの位置に「読み込み中…」。保存中は、フォーム全体を無効にする。 |
| 空 | SCR-002 と同じ。 |
| エラー | SCR-002 と同じ。レシピが存在しない、削除済み、または他ユーザのものは、「レシピが見つかりません」とし、SCR-001 へ戻れる。 |

保存が成功したら、更新したレシピの SCR-003 へ進む。

## 画面遷移

| 画面 | 操作 | 遷移先 |
|------|------|--------|
| 共通 | 開く（未ログイン） | ログイン画面 URL |
| 共通 | ヘッダの戻る | メニュー画面 URL |
| 共通 | ナビ「レシピ」 | SCR-001 |
| SCR-001 | 新規 | SCR-002 |
| SCR-001 | 行 | SCR-003 |
| SCR-002 | 保存（成功） | SCR-003（登録したレシピ） |
| SCR-002 | キャンセル・戻る | SCR-001 |
| SCR-003 | 戻る | SCR-001 |
| SCR-003 | 編集 | SCR-004 |
| SCR-003 | 削除（確認して成功） | SCR-001 |
| SCR-004 | 保存（成功） | SCR-003（更新したレシピ） |
| SCR-004 | キャンセル・戻る | SCR-003 |

- モーダル（材料の追加、分量名称の追加、削除の確認）は、保存・実行（成功）またはキャンセルで閉じる。保存・実行が失敗したときは、追加のダイアログは閉じずにエラーを示す。

## レイアウトの違い（PC とスマートフォン）

`rules/31-web-app-responsive-layout-spec.md` に従い、業務ロジックは共通、配置だけを変える。

| 画面 | PC（768px 以上） | スマートフォン（768px 未満） |
|------|-------------------|------------------------------|
| 共通 | 左ナビ | 下ナビ（1 項目） |
| SCR-001 | 一覧の行（幅を制限した 1 カラム） | 同じ行を 1 カラムで表示 |
| SCR-002・004 | フォームは幅を制限した 1 カラム。材料の行は、材料と分量を横に並べる。 | 1 カラム。材料の行は、材料の選択欄、分量の行（接頭語・数量・接尾語）を縦に積む。 |
| SCR-003 | 材料一覧と手順を縦に並べる（手順のカードは、幅を制限した 1 カラム）。 | 同じ順で、1 カラムで表示 |

- ページ全体はスクロールさせない。一覧・フォーム本体・詳細本体・ダイアログの中身は、部品内でスクロールしてよい。
- 主なタップ領域は 44px × 44px 以上とする。
