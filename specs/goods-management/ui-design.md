## 画面一覧

| 画面ID | 画面名 | パス | 目的 |
|--------|--------|------|------|
| SCR-001 | 商品一覧 | `/portal_goods_management/` | 人物・アーティスト・媒体による絞り込みと商品一覧。人物・アーティスト・媒体自体の登録・改名・削除。 |
| SCR-002 | 商品登録・編集 | `/portal_goods_management/goods/new`、`/portal_goods_management/goods/:id/edit` | 商品の登録・編集・削除、画像の追加・削除。 |

## 画面詳細

### SCR-001: 商品一覧

**部品配置**

| 領域 | 部品 | 説明 |
|------|------|------|
| コンテンツ上部 | 人物選択 | 未削除の人物から選ぶ。選ぶとアーティスト選択が有効になる。 |
| コンテンツ上部 | アーティスト選択 | 人物選択後に有効。選択中の人物に紐づく未削除のアーティストと「すべて」から選ぶ。選ぶと媒体選択が有効になる。 |
| コンテンツ上部 | 媒体選択 | アーティスト選択後に有効。選択中の人物に紐づく未削除の媒体（重複除去）と「すべて」から選ぶ。選ぶと商品一覧を取得する。 |
| コンテンツ上部 | タイトル絞り込み入力 | 商品一覧を取得済みのときだけ有効。入力した文字列をタイトルに含む商品だけに画面内で絞り込む（大文字小文字を区別しない）。空にすると絞り込みを解除する。 |
| コンテンツ上部 | 設定ボタン | 人物・アーティスト・媒体の管理パネル（下記）を開く。 |
| コンテンツ | 商品一覧 | 条件に合う未削除の商品を一覧表示する（サムネイル、タイトル、媒体名、リリース日、所持バッジ）。行を選ぶと SCR-002（編集）へ遷移する。 |
| コンテンツ | 新規追加ボタン | SCR-002（新規登録）へ遷移する。選択中のアーティスト・媒体があれば初期値として引き継ぐ。 |
| 人物・アーティスト・媒体の管理パネル（モーダル） | 種別タブ（人物／アーティスト／媒体） | 管理対象を切り替える。 |
| 人物・アーティスト・媒体の管理パネル | 対象一覧 | 選択中の種別の未削除の一覧。各行に名称変更ボタン・削除ボタンを持つ。アーティストの行には、所属する人物名を添える。 |
| 人物・アーティスト・媒体の管理パネル | 追加ボタン | 選択中の種別の登録フォームを開く。アーティストの登録フォームは、所属する人物（0件以上）のチェックボックス選択を含む。 |
| 人物・アーティスト・媒体の管理パネル | 登録・名称変更フォーム | 名称の入力（アーティストは所属人物のチェックボックスも）。保存・キャンセルの操作を持つ。 |
| 人物・アーティスト・媒体の管理パネル | 削除確認ダイアログ | 対象の名称を示し、削除してよいか確認する。他のデータから参照されていて削除できない場合は、保存時にエラーメッセージで示す。 |
| 人物・アーティスト・媒体の管理パネル | 閉じるボタン | パネルを閉じ、商品一覧の表示に戻る（絞り込み条件は保持する）。 |

**文言（本機能固有）**

`rules/15-ui-style.md` の共通語彙に無い、本機能固有の操作ラベル。

| 語 | 用途 |
|------|------|
| すべて | アーティスト選択・媒体選択で、個別を指定しない条件 |
| 所持 / 未所持 | 商品一覧の各行に添えるバッジ |
| 人物 / アーティスト / 媒体 | 管理パネルの種別タブ |

管理パネルを開くボタンは `config`（歯車）アイコン、各対象の追加は `plus`、名称変更は `edit`、削除は `delete`、保存は `check`、キャンセル・閉じるは `close` を使う。新規追加ボタン（商品）も `plus` を使う。

**状態別の表示**

| 状態 | 表示内容 |
|------|----------|
| 初期 | 人物一覧の取得を開始する。人物・アーティスト・媒体とも未選択。商品一覧は表示しない。 |
| 読込中 | 領域の中央に「読み込み中…」。操作は無効。 |
| 空（人物なし） | 人物選択の位置に「データがありません」。追加は可能。 |
| 空（アーティストなし） | アーティスト選択の位置に「データがありません」。 |
| 空（媒体なし） | 媒体選択の位置に「データがありません」。 |
| 空（商品なし） | 一覧に「データがありません」。 |
| 空（タイトル絞り込みで0件） | 一覧に「絞り込み条件に一致する商品はありません」。 |
| エラー | 対象領域の先頭にエラーメッセージ（内部理由は出さない）。未ログインは表示せずログイン画面へ進む。 |

登録・変更・削除の成功時は、対象領域の先頭に成功メッセージを数秒表示する。

ページ全体はスクロールさせず、商品一覧および管理パネルの対象一覧だけスクロールする（`rules/15-ui-style.md` の前提に従う）。

### SCR-002: 商品登録・編集

**部品配置**

| 領域 | 部品 | 説明 |
|------|------|------|
| ヘッダ下 | 戻るボタン | 保存・削除をせずに SCR-001 へ戻る。 |
| コンテンツ | 媒体選択 | 未削除の媒体から選ぶ。必須。 |
| コンテンツ | アーティスト選択 | 未削除のアーティストから選ぶ。必須。 |
| コンテンツ | タイトル入力 | 必須。空文字・空白のみは不可。 |
| コンテンツ | リリース日入力 | 任意。省略時、登録では登録日を設定し、編集では既存の値を保持する。 |
| コンテンツ | 所持チェックボックス | 任意。既定は未所持。 |
| コンテンツ | 品番入力 | 任意。 |
| コンテンツ | メモ入力 | 任意（複数行）。 |
| コンテンツ | 画像一覧 | 登録済みの画像をサムネイルで一覧表示する。各画像に削除ボタンを持つ。 |
| コンテンツ | 画像追加ボタン | ファイル選択（PNG/JPEG）で画像を1枚選び、画像一覧に追加する（保存時にまとめて反映）。 |
| コンテンツ下部 | 保存ボタン | 新規登録または更新を実行する。成功すれば SCR-001 へ戻る。 |
| コンテンツ下部 | 削除ボタン | 編集時のみ表示する。削除確認ダイアログを開く。 |
| 削除確認ダイアログ | 確認文言・操作 | 対象のタイトルを示し、削除・キャンセルの操作を持つ。削除に成功すれば SCR-001 へ戻る。 |

**文言（本機能固有）**

| 語 | 用途 |
|------|------|
| 所持 | 所持チェックボックスのラベル |
| 品番 | 品番入力のラベル |

戻るは `back`、画像追加は `plus`、画像の削除・商品の削除は `delete`、保存は `check` を使う。

**状態別の表示**

| 状態 | 表示内容 |
|------|----------|
| 初期（新規） | 空のフォーム。一覧画面で選択中のアーティスト・媒体があれば初期値にする。 |
| 初期（編集） | 対象商品の値と画像一覧を取得して表示する。 |
| 読込中 | 領域の中央に「読み込み中…」。操作は無効。 |
| エラー | フォーム先頭にエラーメッセージ（内部理由は出さない）。対象の商品が取得できない場合はその旨を示し、保存操作は無効にする。 |

## 画面遷移

| 画面 | 操作 | 遷移先 |
|------|------|--------|
| SCR-001 | 人物・アーティスト・媒体を選ぶ | 選択の絞り込みに応じて商品一覧を更新する |
| SCR-001 | 商品一覧の行を選ぶ | SCR-002（編集） |
| SCR-001 | 新規追加ボタン | SCR-002（新規登録） |
| SCR-001 | 設定ボタン | 管理パネルを開く |
| SCR-001（管理パネル） | 追加・名称変更ボタン | 登録・名称変更フォームを開く |
| SCR-001（管理パネル） | 保存 | 成功すれば一覧を更新してフォームを閉じる。失敗すればエラーを示し、フォームは残す。 |
| SCR-001（管理パネル） | 削除ボタン | 削除確認ダイアログを開く |
| SCR-001（管理パネル・削除確認） | 削除 | 成功すれば一覧を更新してダイアログを閉じる。失敗すればエラーを示す（参照制約違反を含む）。 |
| SCR-001（管理パネル） | 閉じるボタン | 管理パネルを閉じ、SCR-001 の商品一覧表示に戻る |
| SCR-002 | 戻るボタン | SCR-001 |
| SCR-002 | 保存ボタン | 成功すれば SCR-001。失敗すればエラーを示し、SCR-002 に留まる。 |
| SCR-002 | 削除ボタン→削除確認 | 成功すれば SCR-001。失敗すればエラーを示す。 |
| いずれか | 開く | 未ログイン時はログイン画面 URL |
| いずれか | 戻る | メニュー画面 URL |
