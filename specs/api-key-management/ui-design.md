# api-key-management（APIキー管理）UI設計

> 色・余白・部品の見た目・共通の操作ラベル・画面分割・ナビは `rules/15-ui-style.md` に従う。
> 起動・モジュール構成は書かない → `design.md`
> API のパス・要求・応答・エラーは書かない → `api-design.md`
> テーブル定義と ER 図は書かない → `db-design.md`

本機能の `--color-primary` は **Amber `#F2C94C`** とする。

対象機能（`goods-management`、`expense-management`、`knowhow-management`、`schedule`）の画面は変更しない。

## 画面詳細

### SCR-001: API キー一覧

**目的**

他システム連携に使う自分の API キーの状態を確認し、必要に応じて発行・失効する。

**情報の優先度**

1. 名前、状態（有効・期限切れ・失効済み）
2. 識別用の先頭部分、有効期限、最終利用日時
3. 発行日時

**主操作**

- 新規（API キーの発行）

**副操作**

- 失効（行ごと）

**部品配置**

ヘッダ・ナビの殻は `rules/15-ui-style.md` に従う。

| 領域 | 部品 | 説明 |
|------|------|------|
| ヘッダ | システムアイコン、タイトル「API キー管理」、戻るボタン | 戻るはシステム設定のメニュー画面 URL へ（アイコン `back`、`aria-label`「戻る」）。 |
| ナビ | 「API キー」 | 項目は 1 つ（現在地として選択中の表示）。アイコンは `config`。 |
| コンテンツ上部 | 見出し「API キー」、説明文、新規ボタン | 説明文（Caption）:「他システムがあなたとして、割り当てられた機能の API を使うためのキーです。キーは第三者に知られないように管理してください。」。新規ボタンは主ボタン（アイコン `new`、`aria-label`「新規」）。 |
| コンテンツ上部 | メッセージ領域 | エラー・成功のメッセージを出す（`rules/15-ui-style.md` の状態の見た目）。 |
| コンテンツ本体 | API キーの一覧 | 発行日時の新しい順。失効済みも含めて全件を出す。ヘッダ行は固定、本体だけスクロール。 |

一覧の項目（1 行 = 1 つの API キー）:

| 項目 | 表示 | 優先度 |
|------|------|--------|
| 名前 | 文字列。長いときは折り返す（横スクロールしない）。 | Primary |
| 状態 | 「有効」「期限切れ」「失効済み」のラベル。色だけに頼らず文字で示す。有効は `--color-primary` の枠、期限切れ・失効済みは `--color-text-muted` の文字。 | Secondary |
| 識別用の先頭部分 | 例 `wak_Ab3dEf7h…`（末尾に「…」を付け、全体ではないことを示す）。等幅フォント。 | Secondary |
| 有効期限 | `YYYY-MM-DD HH:mm`。無期限は「無期限」。 | Secondary |
| 最終利用日時 | `YYYY-MM-DD HH:mm`。未使用は「未使用」。 | Tertiary |
| 発行日時 | `YYYY-MM-DD HH:mm`。 | Tertiary |
| 失効日時 | 失効済みのときだけ `YYYY-MM-DD HH:mm` を「失効: 」に続けて出す。 | Tertiary |
| 失効ボタン | 状態が「有効」「期限切れ」の行だけに出す。テキストボタン、文字色 `--color-danger`（アイコン `stop`、`aria-label`「失効」）。失効済みの行には出さない。 | - |

日時はブラウザのローカル時刻で表示する。

**PC（768px 以上）のレイアウト**

- ナビ: 左に固定。
- 一覧: 表形式。列は「名前 / 状態 / 先頭部分 / 有効期限 / 最終利用 / 発行日時 / 操作」。失効日時は状態の下に小さく出す。
- 新規ボタン: 見出しの右。

**スマートフォン（768px 未満）のレイアウト**

- ナビ: 下端に固定。
- 一覧: 1 カラムのカード。カード内は上から「名前と状態」「先頭部分」「有効期限・最終利用日時」「発行日時（・失効日時）」の順。失効ボタンはカードの右上。
- 新規ボタン: 見出しの右（片手で届く位置を保つため、コンテンツ上部に固定し、一覧だけをスクロールする）。

**状態別の表示**

| 状態 | 表示内容 |
|------|----------|
| 初期 | 一覧を取得する（読込中の表示）。 |
| 読込中 | 一覧の領域の中央に「読み込み中…」。新規ボタンは無効。 |
| 空 | 一覧の本体に「データがありません」。新規ボタンは有効。 |
| エラー | メッセージ領域に「API キーの一覧を取得できませんでした。」（`--color-danger`）。新規ボタンは有効。 |
| 未ログイン | システム設定のログイン画面 URL へ遷移する。 |
| 権限なし | メッセージ領域に「この機能を利用する権限がありません。」。一覧と新規ボタンは出さない。 |
| 成功（失効後） | メッセージ領域に「API キーを失効しました。」。数秒で消す。 |

**アクセシビリティ**

- キーボード: 新規ボタン、各行の失効ボタンへ Tab で移動できる。
- フォーカス: `--color-primary` の枠。
- ラベル: アイコンのみのボタンに `aria-label`（「新規」「失効」「戻る」）。
- タッチ: ボタンは 44px × 44px 以上。

### DLG-001: 発行

**部品配置**

| 領域 | 部品 | 説明 |
|------|------|------|
| 見出し | 「API キーの発行」 | |
| 本体 | 名前（入力、必須） | 1 行のテキスト入力。プレースホルダ「例: 家計簿連携」。 |
| 本体 | 有効期限（入力、任意） | 日付と時刻の入力。空のときは無期限。下に Caption「空欄のときは無期限になります。」。 |
| 本体 | エラー表示 | 入力の検証エラー・発行の失敗を先頭に出す。 |
| 操作 | キャンセル、発行 | キャンセルは副ボタン（アイコン `close`、`aria-label`「キャンセル」）。発行は主ボタン（アイコン `check`、`aria-label`「発行」）。 |

**入力の検証（送信前）**

| 条件 | 表示 |
|------|------|
| 名前が空（前後の空白を除く） | 「名前を入力してください。」 |
| 有効期限が現在以前 | 「有効期限には未来の日時を指定してください。」 |

**状態別の表示**

| 状態 | 表示内容 |
|------|----------|
| 初期 | 名前・有効期限とも空。名前にフォーカス。 |
| 送信中 | 発行・キャンセルボタンを無効にする。 |
| エラー | 先頭に「API キーを発行できませんでした。」、または上記の検証の文言（`--color-danger`）。入力は保持する。 |

- 背景（オーバーレイ）のクリックでは閉じない。
- スマートフォンでは、画面下からのシート（Bottom Sheet）として開く。

### DLG-002: 発行結果

**部品配置**

| 領域 | 部品 | 説明 |
|------|------|------|
| 見出し | 「API キーを発行しました」 | |
| 本体 | 注意書き | `--color-danger` の文字で「このキーは今しか表示されません。閉じる前にコピーして、安全な場所に保管してください。」 |
| 本体 | 名前 | 発行した API キーの名前。 |
| 本体 | キー全体 | 読み取り専用の等幅表示。長いときは折り返す。全選択しやすいように、押すと全体が選択される。 |
| 本体 | コピーボタン | 文字ラベル「コピー」の副ボタン（対応するアイコンが無いため文字ラベルとする）。押すとクリップボードへ書き込み、直下に「コピーしました」を数秒出す。書き込めないときは「コピーできませんでした。キーを選択してコピーしてください。」。 |
| 本体 | 使い方の説明 | Caption: 「他システムからは、要求ヘッダ `Authorization: Bearer <キー>` として送ってください。」 |
| 操作 | 閉じる | 主ボタン（アイコン `close`、`aria-label`「閉じる」）。 |

- 背景（オーバーレイ）のクリックでは閉じない。閉じるボタンだけで閉じる。
- 閉じたら、キー全体を画面の状態から破棄し、SCR-001 の一覧を取得し直す。
- スマートフォンでは、画面下からのシートとして開く。

### DLG-003: 失効の確認

**部品配置**

| 領域 | 部品 | 説明 |
|------|------|------|
| 見出し | 「API キーの失効」 | |
| 本体 | 確認文 | 「次の API キーを失効します。失効したキーは元に戻せず、このキーを使っている他システムは利用できなくなります。」 |
| 本体 | 対象 | 名前と識別用の先頭部分。 |
| 本体 | エラー表示 | 失効の失敗を先頭に出す。 |
| 操作 | キャンセル、失効 | キャンセルは副ボタン（アイコン `close`、`aria-label`「キャンセル」）。失効は `--color-danger` の文字の副ボタン（アイコン `stop`、`aria-label`「失効」）。主ボタンとは見た目と位置を分ける。 |

**状態別の表示**

| 状態 | 表示内容 |
|------|----------|
| 初期 | 確認文と対象を表示。キャンセルにフォーカス。 |
| 送信中 | 失効・キャンセルボタンを無効にする。 |
| エラー | 先頭に「API キーを失効できませんでした。」（`--color-danger`）。 |

- 背景（オーバーレイ）のクリックでは閉じない。
