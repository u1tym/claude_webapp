# API設計: mail-notice（メール通知）

## 概要

本機能は HTTP API を持たない。FastAPI と uvicorn は使わない。判定とメール送信はコンソールアプリケーション（`python -m app`）が 1 回実行して終了する。`requirements.md` の該当 REQ を満たすことだけを書く。テーブル定義は `db-design.md` を参照する。

関連ドキュメント:

- 全体設計: `design.md`
- UI設計: `ui-design.md`
- DB設計: `db-design.md`

## 共通

### 認証

認証しない。401 / 403 は使わない。セッション Cookie、機能マスタ、メニュー割当は用いない。

### エラー（共通）

HTTP 応答は無い。失敗はログへ出す。本文を返すインタフェースは持たない。

| 状況 | 応答 |
|------|------|
| （なし） | HTTP を使わない |
