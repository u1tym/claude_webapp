**部品配置**

| 詳細表示（モーダル） | 関連（契約を伴う契約のみ） | 依存契約の名称、支払方法の名称（どちらも、選ぶとその契約の詳細に切り替わるリンク）。「この契約に依存している契約」「この契約を支払方法としている契約」の名称（同じくリンク）。無いときは「-」。 |

**文言（本機能固有）**

`rules/15-ui-style.md` の共通語彙に無く、対応するアイコンも無い操作は、文字ラベルのボタンとする（同ルールの「対応するアイコンが無い操作は文字ラベルのボタンのままにする」の適用）。

| 語 | 用途 |
|------|------|
| 検索 | 検索欄のプレースホルダ |
| コピー | 値をクリップボードへコピーするボタン（コピー直後は「コピー済」に変わり、数秒で戻る） |
| 表示 / 隠す | パスワードのマスク表示・平文表示を切り替えるボタン。マスク中は「表示」、平文表示中は「隠す」 |
| パスワード未設定 | パスワードが未設定の契約に付けるバッジ |

**状態別の表示**

| 状態 | 表示内容 |
|------|----------|
| 初期 | 一覧取得を開始する。検索欄は空。絞り込みは既定。 |
| 読込中 | 領域の中央に「読み込み中…」。操作は無効。 |
| 空 | 絞り込み・検索が無いときは「データがありません」。あるときは「該当するデータがありません」。いずれも新規登録は可能。 |
| エラー | 対象領域の先頭にエラーメッセージ（内部理由は出さない）。未ログインは表示せずログイン画面へ進む。保存の失敗は、フォーム内にメッセージを示し、フォームは残す。 |

新規登録・編集・削除の成功時は、対象領域の先頭に成功メッセージを数秒表示する。契約一覧はページ全体をスクロールさせず、一覧本体だけスクロールする。

### SCR-003: 区分

**部品配置**

| 領域 | 部品 | 説明 |
|------|------|------|
| コンテンツ上部 | 区分の追加欄 | 区分名の入力欄と、「金融機関」のチェック、追加ボタン（新規のアイコン）。 |
| コンテンツ | 区分の一覧 | 区分の名称と、金融機関の区分には「金融機関」の文字のバッジ、編集ボタン（編集のアイコン）、削除ボタン（削除のアイコン）を持つ行の一覧。「その他」は、編集・削除のボタンを出さない。編集ボタンを押すと、その行の名称が入力欄に、「金融機関」がチェックになり、保存・キャンセルの操作が出る。金融機関の指定を外せないとき（その区分の契約が支払方法になっているとき）は、「支払方法として使われているため、金融機関の指定を外せません」を、一覧の先頭に表示する。 |
| 削除確認ダイアログ | 確認文言と操作 | 対象の区分名を示し、削除してよいか確認する。削除・キャンセル。 |

使われている区分を削除しようとしたときは、「使用中のため削除できません」を、一覧の先頭に表示する。

**状態別の表示**

| 状態 | 表示内容 |
|------|----------|
| 初期 | 区分の一覧取得を開始する。「その他」は必ず表示される。 |
| 読込中 | 領域の中央に「読み込み中…」。操作は無効。 |
| 空 | 「その他」以外の区分が無いときも、「その他」の行は表示する。 |
| エラー | 対象領域の先頭にエラーメッセージ（内部理由は出さない）。名称の重複・空白は、入力欄の近くに示す。未ログインは表示せずログイン画面へ進む。 |

### SCR-004: 解約順

**部品配置**

| 領域 | 部品 | 説明 |
|------|------|------|
| コンテンツ上部 | 操作 | 保存ボタン、PDF 出力ボタン。PDF 出力は、解約の対象が 0 件のとき、または未保存の変更があるときは無効にし、理由を併記する（保存した解約順で出力するため）。 |
| コンテンツ上部 | 警告 | 解約順が、依存契約の関係と逆になっているとき、「『A』は『B』に依存しています。『B』が先に解約される並びです」の形で、該当をすべて示す。警告があっても保存できる。 |
| コンテンツ | 解約順の一覧 | 解約の対象を、解約する順に、番号付きで並べる。各行に、名称、解約方法（長いときは先頭の数行）、依存契約の名称を表示する。行ごとに、「上へ」「下へ」のボタン（先頭は「上へ」、末尾は「下へ」を無効にする）と、対象から外すボタンを置く。0 件のときは「解約の対象がありません」。 |
| コンテンツ | 対象にできる契約の一覧 | 契約を伴う契約で、ステータスが有効または休止中で、まだ解約の対象に加えていないもの。名称、区分、解約方法の有無を表示し、「加える」ボタンで、解約順の一覧の末尾に加える。名称で絞り込める。 |
| 印刷用の領域（画面には出さない） | 解約手順 | PDF 出力で使う。見出し「解約手順」と出力日、解約順の番号、名称、解約方法を、解約順に並べる。解約方法が未入力の契約は「未入力」と表示する。パスワード、ユーザ名、登録メールアドレスは出さない。 |

PC では、解約順の一覧と、対象にできる契約の一覧を、左右に並べてよい。スマートフォンでは、縦に並べる（解約順の一覧が先）。並べ替えは、「上へ」「下へ」のボタンで行う（ドラッグだけにしない）。

**文言（本機能固有）**

| 語 | 用途 |
|------|------|
| 上へ / 下へ | 解約順の並べ替え（文字ラベルのボタン） |
| 加える | 対象にできる契約を、解約順に加える（文字ラベルのボタン） |
| PDF出力 | 解約手順を、ブラウザの印刷機能で出力する（文字ラベルのボタン） |

**状態別の表示**

| 状態 | 表示内容 |
|------|----------|
| 初期 | 保存済みの解約順と、対象にできる契約を取得する。 |
| 読込中 | 領域の中央に「読み込み中…」。操作は無効。 |
| 空 | 解約順の一覧に「解約の対象がありません」。対象にできる契約も 0 件のときは「データがありません」。 |
| エラー | 対象領域の先頭にエラーメッセージ（内部理由は出さない）。未ログインは表示せずログイン画面へ進む。 |

保存の成功時は、対象領域の先頭に成功メッセージを数秒表示する。未保存の変更があるときは、「未保存の変更があります」を、操作の近くに示す。

## 要件トレーサビリティ
